```jsx
import Contents from "@niceprototypes/contents"

<Contents
  items={[
    { id: "docs", label: "Docs" },
    { id: "props", label: "Props", items: [{ id: "size", label: "size" }] },
  ]}
/>
```

Each `id` is the id of a section on the page. Scroll-spy marks the section whose top has passed the upper quarter of the viewport; a click scrolls smoothly to its section. Give the sections a `scroll-margin-top` to clear a fixed header. This page's own Contents column is one.
