# Image — RenderImage

Escape hatch: replace the default `<img>` / `<div>` rendering with a custom
element. Useful for delegating to a framework-specific image component
(e.g. `next/image`, a CDN loader, or a responsive `<picture>` element).
Width, height, backgroundSize, borderRadius, and other style props are
ignored when `renderImage` is provided.

<DocsRow spacing="large none">
  <Image
    src={DEMO_IMAGE}
    alt="Custom picture element"
    renderImage={(src, alt) => (
      <picture>
        <source srcSet={src} type="image/jpeg" />
        <img src={src} alt={alt} width={200} style={{ border: "2px dashed currentColor", padding: 4 }} />
      </picture>
    )}
  />
