<Ink color="light">defers unrendering after the trigger ends. Both are in milliseconds and default to</Ink>
<Ink color="light" code>0</Ink><Ink color="light">. A pending delay is cancelled if the opposite event fires first, so a brief pass never flashes the tooltip.</Ink>
