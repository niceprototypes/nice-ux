## Guide

Form renders a semantic `<form>` and stacks its direct children in a column. It applies no spacing between them; wrap them in a Flex for a gap. It owns no field state: the consumer manages values, through controlled inputs or `FormData` read from the submit event.

By default Form calls `event.preventDefault()` before `onSubmit`, the single-page-app behavior. Set `preventDefault={false}` to let a native submission run:

```jsx
<Form onSubmit={onSubmit} />                         // default-prevented
<Form preventDefault={false} onSubmit={onSubmit} />  // native submission
```

`theme` pins token resolution for the form and everything inside it.

<Callout type="hint">Form has no gap of its own — space its children with a Flex.</Callout>
