<Ink as="h2">Guide</Ink>

<Ink><Ink code>@niceprototypes/field</Ink> <Ink>has named exports only, no default export.</Ink></Ink>

<Ink><Ink>Field renders a native</Ink> <Ink code>{"<label>"}</Ink><Ink>, the control, an optional description and an always-mounted polite live region for the error. It publishes the wiring through context; the control applies it. Input, and everything built on it (Select, DateField), already does:</Ink></Ink>

<ul>
  <li><Ink><code>id</code> — the control takes the Field's id, so the label's <code>htmlFor</code> names it. It defaults to <code>useId()</code>; pass <code>id</code> to fix it.</Ink></li>
  <li><Ink><code>aria-describedby</code> — ordered <code>[description, error, own]</code>. The error id is present only while there is an error.</Ink></li>
  <li><Ink><code>aria-invalid="true"</code> — only while the Field is <code>invalid</code>, never <code>"false"</code>. It changes no style; set <code>status="error"</code> on the control.</Ink></li>
  <li><Ink><code>required</code> — native <code>required</code> on the control. The label renders no asterisk; mark the other fields with <code>optionalLabel</code> instead.</Ink></li>
</ul>

<Ink>In development, Field warns in the console when no element inside it carries the id — the silent failure where the label names nothing.</Ink>

<Ink><Ink code>Fieldset</Ink> <Ink>groups related controls under a native</Ink> <Ink code>{"<fieldset>"}</Ink><Ink>.</Ink> <Ink code>legend</Ink> <Ink>is required and names the group;</Ink> <Ink code>description</Ink> <Ink>follows it and is referenced by the fieldset's</Ink> <Ink code>aria-describedby</Ink><Ink>.</Ink> <Ink code>disabled</Ink> <Ink>is the native attribute and disables every control inside.</Ink></Ink>

```jsx
<Fieldset legend="Shipping address" description="Where the order is delivered.">
  <Field label="Street and number"><Input /></Field>
  <Field label="Postcode"><Input width="10" /></Field>
</Fieldset>
```

<Ink><Ink>A custom control reads the wiring with</Ink> <Ink code>useField()</Ink><Ink>, which returns</Ink> <Ink code>{"{ id, labelId, descriptionId?, errorId?, describedBy?, invalid, required }"}</Ink><Ink>, or</Ink> <Ink code>null</Ink> <Ink>outside a Field.</Ink> <Ink code>mergeDescribedBy(fieldDescribedBy, own)</Ink> <Ink>joins the two id lists in order, drops empty entries, keeps the first occurrence of each id, and returns</Ink> <Ink code>undefined</Ink> <Ink>when nothing is left, so no empty attribute renders.</Ink></Ink>

```jsx
const field = useField()

<input
  id={field?.id}
  aria-describedby={mergeDescribedBy(field?.describedBy, ownDescribedBy)}
  aria-invalid={field?.invalid ? true : undefined}
  required={field?.required}
/>

mergeDescribedBy("f-desc f-err", "hint f-desc") // "f-desc f-err hint"
mergeDescribedBy(undefined, undefined)          // undefined
```

<Callout type="hint">Field only publishes the wiring — the control must apply `id`, `aria-describedby`, `aria-invalid` and `required`. Input does this for you.</Callout>
