<StoryHeader title="Linking" />

<Ink as="span">Link a Nice package into the current project via a <code>file:</code> reference, then strip its duplicate singletons in one step.</Ink>

```bash
# Link a single package (long form)
npx nice-toolkit ../react-button

# Short alias
nicely ../react-button

# Link several — one call each
nicely ../react-button
nicely ../react-icon
nicely ../react-flex
```

<Ink as="span">Linking rewrites the dependency to <code>file:../react-button</code> and runs a dedupe pass on the linked package so its <code>node_modules</code> doesn't shadow the app's React / styled-components.</Ink>

<Line />

<Ink as="h2"><Code code="--unlink" language="bash" inlined /></Ink>

<Ink as="span">Restore every <code>file:</code> reference to its original npm version and reinstall from the registry.</Ink>

```bash
nicely --unlink

# Preview what would be unlinked
nicely --unlink --dry-run
```

<Ink as="span">Run <code>--unlink</code> before <code>npm install</code> inside a linked package (or re-run <code>nicely</code> afterward) — a fresh install reintroduces the singleton duplicates that linking removed.</Ink>

<Line />

<Ink as="h2"><Code code="--exclude" language="bash" inlined /> / <Code code="--add-exclude" language="bash" inlined /></Ink>

<Ink as="span">The default singleton set removed from linked packages is <code>react</code>, <code>react-dom</code>, <code>styled-components</code>, <code>@types/react</code>, <code>@types/react-dom</code>.</Ink>

```bash
# Replace the default set entirely
nicely --exclude react,react-dom ../my-component

# Extend the default set
nicely --add-exclude @emotion/react,@emotion/styled ../my-component
```

<Line />

<Ink as="h2"><Code code="--manager" language="bash" inlined /> / <Code code="--skip-peer-check" language="bash" inlined /></Ink>

```bash
# Force a package manager (auto-detected from the lockfile by default)
nicely --manager pnpm ../my-component

# Skip auto-moving react / react-dom into peerDependencies
nicely --skip-peer-check ../my-component
```
