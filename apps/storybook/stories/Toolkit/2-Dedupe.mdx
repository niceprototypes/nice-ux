<StoryHeader title="Dedupe" />

<Ink as="span">Remove duplicate singleton packages (react, styled-components, etc.) from linked packages' <code>node_modules</code>. This is the fix for <Ink as="span" weight="semibold">"Invalid hook call"</Ink> and styled-components context mismatches — both caused by more than one copy of a singleton being loaded at runtime.</Ink>

```bash
# Recurse across every file: linked package
nicely --dedupe

# Scope to one package
nicely --dedupe ../react-button

# Preview without deleting anything
nicely --dedupe --dry-run
```

<Line />

<Ink as="h2">What it removes</Ink>

<Ink as="span">By default these are stripped from each linked package so the app's copy is the only one loaded:</Ink>

```bash
• react
• react-dom
• styled-components
• @types/react
• @types/react-dom
```

<Ink as="span">Override or extend the set per run with <code>--exclude</code> / <code>--add-exclude</code> (see <a href="/?path=/docs/toolkit-1-linking--docs" target="_top">Linking</a>).</Ink>

<Line />

<Ink as="h2">When to run it</Ink>

<ul>
  <li><Ink as="span">After <code>npm install</code> inside a linked package (install re-adds the duplicates).</Ink></li>
  <li><Ink as="span">After changing any <code>package.json</code> dependencies.</Ink></li>
  <li><Ink as="span">Any time you hit "Invalid hook call" or a styled-components theme/context</Ink></li>
</ul>
  mismatch while developing against linked packages.

```bash
# Typical sequence after touching a linked package's deps
npm install
nicely --dedupe
```

<Ink as="span"><code>--dedupe</code> is also the second step of the workspace triad and of <code>--reset</code> — see <a href="/?path=/docs/toolkit-5-reset-caches--docs" target="_top">Reset & Caches</a>.</Ink>
