<StoryHeader title="Reset & Caches" />

<Ink as="span">The workspace triad — three commands targeting three distinct, non-overlapping layers — plus <code>--reset</code>, which chains them for the "everything is stale" case. Full cache topology and recipes live in <a href="/?path=/docs/configuration-caches--docs" target="_top">Configuration → Caches</a>.</Ink>

```bash
nicely --clean       # consumer caches + dev-server processes
nicely --dedupe      # singleton conflicts in linked packages
nicely --build-all   # rebuild every linked package's dist
```

<Line />

<Ink as="h2"><Code code="--clean" language="bash" inlined /></Ink>

<Ink as="span">Kills any process bound to a dev-server port (discovered from each consumer's <code>.env</code> <code>PORT=</code> entries and <code>package.json</code> <code>-p</code> / <code>--port</code> flags), then wipes <code>node_modules/.cache</code> and <code>node_modules/.vite</code> across every consumer.</Ink>

```bash
nicely --clean

# Preview
nicely --clean --dry-run

# Skip the port-kill phase (CI / scripted contexts)
nicely --clean --no-kill
```

<Ink as="span">The port-kill matters because a running dev server holds an in-memory module graph and repopulates its on-disk cache on the next request — wiping the cache without stopping the server is a no-op against the symptom.</Ink>

<Line />

<Ink as="h2"><Code code="--reset" language="bash" inlined /></Ink>

<Ink as="span">Chains the triad in the order that matters: <code>--build-all → --dedupe → --clean</code>.</Ink>

```bash
nicely --reset

# Preview the whole sequence
nicely --reset --dry-run
```

<ul>
  <li><Ink as="span"><Ink as="span" weight="semibold">build first</Ink> so the new dists exist,</Ink></li>
  <li><Ink as="span"><Ink as="span" weight="semibold">dedupe second</Ink> so any duplicate singletons that crept in during the build</Ink></li>
</ul>
  cascade are removed,
<ul>
  <li><Ink as="span"><Ink as="span" weight="semibold">clean last</Ink> so dev-server caches are flushed and processes killed before</Ink></li>
</ul>
  the next restart.

<Ink as="span"><code>--reset</code> also <Ink as="span" weight="semibold">stops any running <code>nicely --dev</code>/<code>--watch</code> first</Ink> — those write the same dists the rebuild does, so leaving them running would race. Exit code reflects <code>--build-all</code>'s result; <code>--dedupe</code> and <code>--clean</code> run regardless.</Ink>

<Ink as="span">Use <code>--reset</code> after any refactor that touches a foundation package (token renames, type narrowing in <code>nice-styles</code>, etc.), then restart your dev server.</Ink>
