<Ink as="h2">"Invalid hook call"</Ink>

<Ink>More than one copy of React (or styled-components) is loaded. Strip the duplicates from linked packages:</Ink>

```bash
nicely --dedupe
```

<Line />

<Ink as="h2">Source changes not appearing</Ink>

<Ink as="span">Make sure the rebuild loop is running so a linked package's dist updates on change:</Ink>

```bash
nicely --dev --watch   # separate terminal, alongside your dev server
```

<Ink as="span">If a change still doesn't show, the dev server is holding a stale cache — bounce it:</Ink>

```bash
nicely --vite          # wipes .vite + kills the dev-server port; restart after
```

<Line />

<Ink as="h2">Icon (SVG) edits not updating</Ink>

<Ink as="span">Editing an SVG <Ink as="span" weight="semibold">does</Ink> rebuild the icon chain under <code>nicely --dev --watch</code> — <code>nice-icons</code> regenerates its index and <code>nice-react-icon</code>'s dist is rebuilt. The snag is on the dev-server side: <code>nice-react-icon</code> is consumed from <Ink as="span" weight="semibold">dist</Ink> (it can't be source-aliased because of SVGR), and a Vite dev server such as Storybook keeps serving its already-transformed copy until it's bounced.</Ink>

<Ink as="span">So the fix is to refresh the dev server, not to rebuild again:</Ink>

```bash
# The rebuilt dist already exists — just make the server re-read it
nicely --vite
# then restart the dev server (Storybook, etc.)
```

<Ink as="span">Only reach for <code>nicely --build-icons</code> when <code>nice-react-icon</code>'s dist is actually stale (e.g. you edited icons while no watcher was running). Do <Ink as="span" weight="semibold">not</Ink> run <code>--build-icons</code> while <code>--dev --watch</code> is live — they rebuild the same dist and race; <code>--build-icons</code> will prompt you to stop the watcher first.</Ink>

<Line />

<Ink as="h2">After installing dependencies in a linked package</Ink>

<Ink as="span"><code>npm install</code> reintroduces the singleton duplicates. Either unlink first, or re-dedupe after:</Ink>

```bash
# Option 1 — unlink before installing
nicely --unlink
cd ../react-button && npm install
cd - && nicely ../react-button

# Option 2 — re-dedupe after installing
cd ../react-button && npm install
cd - && nicely --dedupe
```

<Line />

<Ink as="h2">Everything is stale after a foundation refactor</Ink>

```bash
nicely --reset   # --build-all → --dedupe → --clean, then restart the dev server
```
