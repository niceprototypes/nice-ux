<StoryHeader title="Dev & Watch" />

<Ink>Keep linked packages rebuilding — and consumers reloading — as you edit their source. Two flags, usually run together.</Ink>

<Line />

<Ink as="h2"><Code code="--dev" language="bash" inlined /></Ink>

<Ink>Runs</Ink>
<Ink code>npm run dev</Ink>
<Ink>(the package's rollup/gen watcher) in every linked package concurrently, rebuilding each on source change. Packages without a</Ink>
<Ink code>dev</Ink>
<Ink>script are skipped.</Ink>

```bash
nicely --dev
```

<Line />

<Ink as="h2"><Code code="--watch" language="bash" inlined /></Ink>

<Ink>Watches each linked package's</Ink>
<Ink code>dist/</Ink>
<Ink>folder and touches a trigger file when a build lands, which makes webpack/CRA recompile.</Ink>

```bash
nicely --watch

# Watch a different folder (default: dist)
nicely --watch --watch-dir build
```

<Ink as="h4">CRA / webpack setup</Ink>

<Ink>Import the trigger file from your entry point and git-ignore it:</Ink>

```typescript
// src/index.tsx
import './.symlink-trigger.js'
```

```bash
# .gitignore
.symlink-trigger.js
```

<Ink>Vite projects (Storybook, Vite apps) use</Ink>
<Ink code>nice-vite-watcher</Ink>
<Ink>instead of the trigger file — the plugin watches linked dists directly.</Ink>

<Line />

<Ink as="h2"><Code code="--dev --watch" language="bash" inlined /> (recommended)</Ink>

<Ink>Combines both: rebuild on source change</Ink>
<Ink weight="semibold">and</Ink>
<Ink>trigger the consumer to reload.</Ink>

```bash
# package.json
"scripts": {
  "watch:deps": "nicely --dev --watch"
}
```

```bash
npm start          # Terminal 1 — your dev server
npm run watch:deps # Terminal 2 — the rebuild + reload loop
```

<Ink as="h4">Flow</Ink>

```bash
Source change in a linked package
       ↓
--dev runs the package's rollup/gen rebuild
       ↓
dist/ updates
       ↓
--watch detects the dist change → touches .symlink-trigger.js
       ↓
CRA / webpack recompiles  (Vite: nice-vite-watcher reloads)
```

<Line />

<Ink as="h2">Don't run a one-shot build alongside it</Ink>

<Ink code>--dev --watch</Ink>
<Ink>writes the same dist files a</Ink>
<Ink code>--build-all</Ink>
<Ink>/</Ink>
<Ink code>--build-icons</Ink>
<Ink>pass does. Running both at once races on</Ink>
<Ink code>dist/</Ink><Ink>.</Ink>
<Ink code>--build-icons</Ink>
<Ink>guards against this by prompting to stop the watcher first (see</Ink>
<Ink><a href="/?path=/docs/toolkit-3-building--docs" target="_top">Building</a></Ink><Ink>);</Ink>
<Ink code>--reset</Ink>
<Ink>stops it automatically.</Ink>

<Callout><Ink>Editing an icon while <code>--dev --watch</code> runs rebuilds <code>nice-react-icon</code>'s dist correctly, but a Vite dev server (Storybook) may keep serving its cached copy until bounced — see <a href="/?path=/docs/toolkit-7-troubleshooting--docs" target="_top">Troubleshooting → icons not updating</a>.</Ink></Callout>
