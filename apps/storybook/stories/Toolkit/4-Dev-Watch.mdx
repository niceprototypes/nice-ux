<StoryHeader title="Dev & Watch" />

<Ink as="span">Keep linked packages rebuilding — and consumers reloading — as you edit their source. Two flags, usually run together.</Ink>

<Line />

<Ink as="h2"><Code code="--dev" language="bash" inlined /></Ink>

<Ink as="span">Runs <code>npm run dev</code> (the package's rollup/gen watcher) in every linked package concurrently, rebuilding each on source change. Packages without a <code>dev</code> script are skipped.</Ink>

```bash
nicely --dev
```

<Line />

<Ink as="h2"><Code code="--watch" language="bash" inlined /></Ink>

<Ink as="span">Watches each linked package's <code>dist/</code> folder and touches a trigger file when a build lands, which makes webpack/CRA recompile.</Ink>

```bash
nicely --watch

# Watch a different folder (default: dist)
nicely --watch --watch-dir build
```

<Ink as="h4">CRA / webpack setup</Ink>

<Ink as="span">Import the trigger file from your entry point and git-ignore it:</Ink>

```typescript
// src/index.tsx
import './.symlink-trigger.js'
```

```bash
# .gitignore
.symlink-trigger.js
```

<Ink as="span">Vite projects (Storybook, Vite apps) use <code>nice-vite-watcher</code> instead of the trigger file — the plugin watches linked dists directly.</Ink>

<Line />

<Ink as="h2"><Code code="--dev --watch" language="bash" inlined /> (recommended)</Ink>

<Ink as="span">Combines both: rebuild on source change <Ink as="span" weight="semibold">and</Ink> trigger the consumer to reload.</Ink>

```bash
# package.json
"scripts": {
  "watch:deps": "nicely --dev --watch"
}
```

```bash
npm start          # Terminal 1 — your dev server
npm run watch:deps # Terminal 2 — the rebuild + reload loop
```

<Ink as="h4">Flow</Ink>

```bash
Source change in a linked package
       ↓
--dev runs the package's rollup/gen rebuild
       ↓
dist/ updates
       ↓
--watch detects the dist change → touches .symlink-trigger.js
       ↓
CRA / webpack recompiles  (Vite: nice-vite-watcher reloads)
```

<Line />

<Ink as="h2">Don't run a one-shot build alongside it</Ink>

<Ink as="span"><code>--dev --watch</code> writes the same dist files a <code>--build-all</code> / <code>--build-icons</code> pass does. Running both at once races on <code>dist/</code>. <code>--build-icons</code> guards against this by prompting to stop the watcher first (see <a href="/?path=/docs/toolkit-3-building--docs" target="_top">Building</a>); <code>--reset</code> stops it automatically.</Ink>

<Callout><Ink as="span">Editing an icon while <code>--dev --watch</code> runs rebuilds <code>nice-react-icon</code>'s dist correctly, but a Vite dev server (Storybook) may keep serving its cached copy until bounced — see <a href="/?path=/docs/toolkit-7-troubleshooting--docs" target="_top">Troubleshooting → icons not updating</a>.</Ink></Callout>
