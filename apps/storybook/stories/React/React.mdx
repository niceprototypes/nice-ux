React bindings for the Nice design system. These packages wrap `nice-styles`
with providers, hooks, and pre-built components.

---

### Styles

The `nice-react-styles` package adds a provider, font loading, and a typed
token API on top of the base CSS tokens.

- [StylesProvider](/docs/react-styles-stylesprovider--docs) — Context provider
  that injects CSS variables onto `:root` and supplies a styled-components theme
- [FontLoader](/docs/react-styles-fontloader--docs) — Async web font loading
  (used internally by `StylesProvider`)
- [getToken](/docs/react-styles-gettoken--docs) — Typed accessor for token keys,
  CSS `var()` strings, and resolved values
- [setTokens](/docs/react-styles-settokens--docs) — Register a custom token
  map and get back `GlobalStyles` plus a scoped `getToken`

### Bindings

- [useDeviceDetector](/docs/react-hooks-usedevicedetector--docs) — Returns
  whether the current viewport is mobile
