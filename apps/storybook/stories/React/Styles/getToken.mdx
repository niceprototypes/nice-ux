<DocsTitle title="getToken" />

Resolves a design token. Three sibling functions return the three accessor forms:

- `getToken(name, variant?, mode?)` — the `var(...)` reference (the common case).
- `getTokenKey(name, variant?, mode?)` — the bare CSS variable name (no `var(...)` wrapper).
- `getTokenValue(name, variant?, mode?)` — the raw underlying value (e.g. `"16px"`, an hsla color, a font-family string).

See [Browse all tokens](/docs/tokens--docs) for a visual reference of every token group.

```bash
npm install nice-react-styles
```

### Setup

```js
import { getToken, getTokenKey, getTokenValue } from "nice-react-styles"
```

### Usage

```js
getTokenKey("fontSize")            // → "--np--font-size--base"
getToken("fontSize", "large")  // → "var(--np--font-size--large)"
getTokenValue("fontSize", "large") // → "24px"
```

Reach for `getTokenValue` when CSS needs the literal underlying value, not the `var(...)` reference — `parseInt` on a duration, a font-family string passed to a chart library, etc. Reach for `getTokenKey` when emitting raw `@property` or `--custom: var(...)` declarations.
