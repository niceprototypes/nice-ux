# getToken

Resolves a design token to its CSS variable key, `var()` reference, and raw value.
See [Browse all tokens](/docs/tokens-styles--docs) for a visual reference of every token group.

```bash
npm install nice-react-styles
```

### Setup

```js
import { getToken } from "nice-react-styles"
```

### Usage

```js
getToken("fontSize").key // → "--np--font-size--base"
getToken("fontSize", "large").var // → "var(--np--font-size--large)"
getToken("fontSize", "large").value // → "24px"
```
