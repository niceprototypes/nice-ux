# Styles

```bash
npm install nice-react-styles
```

The `nice-react-styles` package wraps `nice-styles` with a React provider,
font loading, and a typed token API for use inside components.

---

### Contents

- [StylesProvider](/docs/react-styles-stylesprovider--docs) — Context provider
  that injects CSS variables onto `:root` and supplies a styled-components theme.
  Wrap your app root with it once.

- **FontLoader** — Handles async web font loading so your layout doesn't shift.
  _(Coming soon)_

- [getReactToken](/docs/react-styles-gettoken--docs) — Typed accessor for token keys,
  CSS `var()` strings, and resolved values. Use it in styled-components template
  literals or inline styles.

- [createTokens](/docs/react-styles-createtokens--docs) — Registers a custom
  token map and returns `GlobalStyles` plus a scoped `getReactToken`. Use it to extend
  the base tokens with project-specific values.

- [setBreakpoints](/docs/react-styles-setbreakpoints--docs) — Overrides the
  pixel thresholds behind `@media` queries. Build-time via `breakpoints.json`
  or runtime via `setBreakpoints` / `createTokens({ breakpoints })`.
