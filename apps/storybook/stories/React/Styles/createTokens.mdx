# createTokens

```bash
npm install nice-react-styles
```

### Setup

```js
import { createTokens, getToken } from "nice-react-styles"
```

### Usage

```js
export const { GlobalStyles } = createTokens(tokenMap)
export { getToken }
```

---

## Overriding an existing variant

Use an existing token key with an existing variant name to replace its value. Here, the base font size is changed from the default to `18px`.

```typescript
createTokens({
  fontSize: {
    base: "18px",
  },
})
```

| CSS variable | Value |
|---|---|
| `--np--font-size--base` | `18px` (overridden) |

---

## Assigning a variant to an existing token

Use an existing token key with a new variant name to extend it. Here, a `brand` variant is added to `color` alongside the existing variants (`base`, `light`, `lighter`, etc.).

```typescript
createTokens({
  color: {
    brand: "#dc0000",
  },
})
```

| CSS variable | Value | Status |
|---|---|---|
| `--np--color--brand` | `#dc0000` | new |
| `--np--color--base` | (default) | unchanged |

---

## Creating a new token

Use a token key that doesn't exist in the base system to create an entirely new token with its own variants.

```typescript
createTokens({
  headerHeight: {
    base: "64px",
    compact: "48px",
  },
})
```

| CSS variable | Value |
|---|---|
| `--np--header-height--base` | `64px` |
| `--np--header-height--compact` | `48px` |

## Responsive variants (breakpoints)

A variant value can be an object with breakpoint keys instead of a plain string. The `phone` value becomes the default, and higher breakpoints override it via media queries. Static strings and breakpoint objects can be mixed within the same token group.

```typescript
createTokens({
  gap: {
    none: "0",                                // static
    small: { phone: "12px", laptop: "16px" }, // responsive
    base: { phone: "24px", laptop: "32px" },  // responsive
  },
})
```

#### Generated CSS

```css
:root {
  --np--gap--none: 0;
  --np--gap--small: 12px;
  --np--gap--small--laptop: 16px;
  --np--gap--base: 24px;
  --np--gap--base--laptop: 32px;
}

@media (min-width: 1280px) {
  :root {
    --np--gap--small: var(--np--gap--small--laptop);
    --np--gap--base: var(--np--gap--base--laptop);
  }
}
```

#### Breakpoints

| Name | Query |
|---|---|
| `phone` | default (no media query) |
| `tablet` | `@media (min-width: 641px)` |
| `laptop` | `@media (min-width: 1280px)` |
| `desktop` | `@media (min-width: 1720px)` |

---

## Mode-aware variants (day/night)

A variant value can be an object with mode keys instead of a plain string. The `day` value becomes the default, and the `night` value is applied via a `prefers-color-scheme` media query. Static strings and mode objects can be mixed within the same token group.

```typescript
createTokens({
  headerColor: {
    base: { day: "#000", night: "#fff" },  // mode-aware
    accent: "#dc0000",                     // static (same in both modes)
  },
})
```

#### Generated CSS

```css
:root {
  --np--header-color--base: #000;
  --np--header-color--base--day: #000;
  --np--header-color--base--night: #fff;
  --np--header-color--accent: #dc0000;
}

@media (prefers-color-scheme: dark) {
  :root {
    --np--header-color--base: var(--np--header-color--base--night);
  }
}
```

#### Primitives

Day and night primitives are stable references that are never reassigned by media queries. Use `getToken` with a mode argument to access them directly.

```typescript
getToken("headerColor", "base", "day")
// → var(--np--header-color--base--day)

getToken("headerColor", "base", "night")
// → var(--np--header-color--base--night)
```

## Putting it all together

All three patterns work in a single call. The token map merges into the existing registry — overriding values where keys match, extending where variants are new, and creating where tokens are new. There is no distinction between "modifying" and "creating." The system overloads the existing tokens transparently.

Variant values can be a plain string, a breakpoint object, or a mode object. These formats can be mixed freely within the same token group and within the same call.

```typescript
const { GlobalStyles } = createTokens({
  fontSize: { base: "18px" },              // override
  color: { brand: "#dc0000" },   // extend
  headerHeight: {                          // create
    base: "64px",
    compact: "48px",
  },
  gap: {                                   // mixed static + responsive
    none: "0",
    base: { phone: "24px", laptop: "32px" },
  },
  headerColor: {                           // mode-aware
    base: { day: "#000", night: "#fff" },
  },
})
```

#### Generated CSS

```css
:root {
  --np--font-size--base: 18px;
  --np--color--brand: #dc0000;
  --np--header-height--base: 64px;
  --np--header-height--compact: 48px;
  --np--gap--none: 0;
  --np--gap--base: 24px;
  --np--gap--base--laptop: 32px;
  --np--header-color--base: #000;
  --np--header-color--base--day: #000;
  --np--header-color--base--night: #fff;
}

@media (min-width: 1280px) {
  :root {
    --np--gap--base: var(--np--gap--base--laptop);
  }
}

@media (prefers-color-scheme: dark) {
  :root {
    --np--header-color--base: var(--np--header-color--base--night);
  }
}
```
