# setBreakpoints

Imperative override of the pixel thresholds behind `@media` queries. `BREAKPOINTS`
is mutated in memory and a `<style data-nice-breakpoints>` element is injected
into `<head>` with the re-emitted `@media` cascade. Cascade order means the
injected stylesheet overrides the build-time literals from `tokens.css`.

For the default thresholds, see
[Tokens/Breakpoints](/docs/tokens-breakpoints--docs). For the declarative
form via `createTokens`, see
[React/Styles/createTokens](/docs/react-styles-createtokens--docs).

---

## Usage

```ts
import { setBreakpoints } from "nice-react-styles"

setBreakpoints({
  tablet: 700,
  laptop: 1100,
  desktop: 1800,
})
```

Accepts `Partial<BreakpointValues>` — any subset of the editable floors
`tablet` / `laptop` / `desktop`; omitted keys are preserved. `phone` is the
implicit mobile-first base and is not settable — its ceiling tracks `tablet`.

Reach for this directly when thresholds need to change after initial load —
a settings toggle, an A/B test, a unit test. For static per-app config that
belongs with the rest of your design tokens, use
[`createTokens({ breakpoints })`](/docs/react-styles-createtokens--docs)
instead.
