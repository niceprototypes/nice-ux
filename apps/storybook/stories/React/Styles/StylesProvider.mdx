# StylesProvider

```bash
npm install nice-react-styles
```

### Setup

```jsx
import { StylesProvider } from "nice-react-styles"
```

### Usage

```jsx
<StylesProvider>{children}</StylesProvider>
```

---

## Basic

Wrap your application with `StylesProvider` to inject nice-styles CSS variables and enable styled-components theming.

```tsx
<StylesProvider>
  {children}
</StylesProvider>
```

This provides CSS custom properties on `:root` and makes the nice-styles `Theme` available via styled-components.
