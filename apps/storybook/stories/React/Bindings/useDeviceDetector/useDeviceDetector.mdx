### Setup

```js
import { useDeviceDetector } from "nice-react-device-detector"
```

### Usage

```js
const isMobile = useDeviceDetector()
```

---

## Basic usage

<Typography color="light">
  Returns a boolean for whether the current viewport is a mobile device.
</Typography>

<CodeRow
  previewCell={<DeviceRow isMobile={useDeviceDetector()} />}
  language="tsx"
  code={`const isMobile = useDeviceDetector()`}
/>

## Conditional rendering

<Typography color="light">
  Branch the rendered output on the detected device type.
</Typography>

<CodeRow
  previewCell={<ConditionalRenderingDemo />}
  language="tsx"
  code={`const isMobile = useDeviceDetector()\nreturn isMobile ? <MobileNav /> : <DesktopNav />`}
/>

## Context provider

<Typography color="light">
  Wrap a subtree in <code>DeviceProvider</code> and read the shared result with{" "}
  <code>useDevice</code> — detection runs once instead of per consumer.
</Typography>

<CodeRow
  previewCell={<ContextProviderDemo />}
  language="tsx"
  code={`<DeviceProvider>\n  <App />\n</DeviceProvider>\n\n// inside any descendant\nconst { isMobile } = useDevice()`}
/>

## Debugging

<Typography color="light">
  Set a <code>debug-mobile</code> entry in <code>localStorage</code> (or append{" "}
  <code>?mobile=true</code> to the URL) to force mobile detection regardless of
  the real viewport.
</Typography>

<CodeRow
  previewCell={<DebuggingDemo />}
  language="tsx"
  code={`localStorage.setItem("debug-mobile", "true")\nwindow.location.reload()`}
/>

## Responsive

<Typography color="light">
  Detection re-evaluates as the viewport crosses the mobile breakpoint. Resize
  the window to watch the values update.
</Typography>

<CodeRow
  previewCell={<ResponsiveDemo />}
  language="tsx"
  code={`const isMobile = useDeviceDetector()\n// re-renders whenever the viewport crosses the breakpoint`}
/>
