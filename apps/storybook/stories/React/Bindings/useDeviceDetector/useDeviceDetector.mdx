## Basic usage

<Typography color="light">
  Returns a boolean for whether the current viewport is a mobile device.
</Typography>

<CodeRow
  cells={[
          <DeviceRow isMobile={useDeviceDetector()} />,
          `const isMobile = useDeviceDetector()`,
        ]}
        columns={[null, { shiki: true }]}

/>

## Conditional rendering

<Typography color="light">

## Context provider

<Typography color="light">
  Wrap a subtree in <code>DeviceProvider</code> and read the shared result with{" "}
  <code>useDevice</code> — detection runs once instead of per consumer.
</Typography>

<CodeRow
  cells={[
          <ContextProviderDemo />,
          `<DeviceProvider>\n  <App />\n</DeviceProvider>\n\n// inside any descendant\nconst { isMobile } = useDevice()`,
        ]}
        columns={[null, { shiki: true }]}
  language="tsx"
  
/>

## Inside StylesProvider

<Typography color="light">
  If the app already renders inside <code>StylesProvider</code>, skip the separate
  provider: pass <code>detectDevice</code> and read the shared value with{" "}
  <code>useDevice</code> from <code>nice-react-styles</code> — one listener, no
  extra provider. See <a href="/docs/react-bindings-usedevice--docs">React/Bindings/useDevice</a>.
</Typography>

<CodeRow
  cells={[
          <StylesProviderDeviceDemo />,
          `import { StylesProvider, useDevice } from "nice-react-styles"\n\n<StylesProvider detectDevice>\n  <App />\n</StylesProvider>\n\n// inside any descendant\nconst { isMobile } = useDevice()`,
        ]}
        columns={[null, { shiki: true }]}
  language="tsx"
/>

## Debugging

<Typography color="light">
  Set a <code>debug-mobile</code> entry in <code>localStorage</code> (or append{" "}
  <code>?mobile=true</code> to the URL) to force mobile detection regardless of
  the real viewport.
</Typography>

<CodeRow
  cells={[
          <DebuggingDemo />,
          `localStorage.setItem("debug-mobile", "true")\nwindow.location.reload()`,
        ]}
        columns={[null, { shiki: true }]}
  language="tsx"
  
/>
