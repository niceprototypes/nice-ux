<StoryHeader title="useDevice" />

Reads the device state published by `StylesProvider`. Returns `{ isMobile }`.
When `StylesProvider` is given `detectDevice`, it runs detection once (via
`nice-react-device-detector`) and shares the result through context — so any
descendant reads one shared value instead of wiring a separate `DeviceProvider`
or calling `useDeviceDetector` per component.

---

## Enable detection on the provider

```tsx
import { StylesProvider } from "nice-react-styles"

<StylesProvider detectDevice>
  <App />
</StylesProvider>
```

`detectDevice` defaults to `false`. When off, no detection runs and no resize
listener is registered — `useDevice()` returns `{ isMobile: false }`.

## Read it anywhere below

```tsx
import { useDevice } from "nice-react-styles"

function Nav() {
  const { isMobile } = useDevice()
  return isMobile ? <HamburgerMenu /> : <FullNavBar />
}
```

No prop drilling — every component under the `StylesProvider` reads the same
`isMobile` directly.

---

## When to use which

| You want… | Use |
|-----------|-----|
| One shared `isMobile` for components under `StylesProvider` | `detectDevice` + `useDevice` |
| Device detection without (or outside) `StylesProvider` | [`useDeviceDetector` / `DeviceProvider`](/docs/react-bindings-usedevicedetector--docs) |

Folding detection into `StylesProvider` costs nothing over a standalone
`DeviceProvider` — it's the same single listener — and removes one provider from
the tree. Prefer it when the app already renders inside `StylesProvider`.
