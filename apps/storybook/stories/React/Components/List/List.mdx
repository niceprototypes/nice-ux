## Guide

List renders a `<ul>` and places a divider between each pair of adjacent rendered children. Each divider is an `<hr>` inside `<li aria-hidden="true" role="presentation">`, since an `<hr>` is not a valid direct child of `<ul>`. `size` reaches every ListItem through context.

ListItem renders one `<li>`: the `start` slot, the content, then the `end` slot. `selected`, `active` and `disabled` are visual states; only `disabled` sets an attribute (`aria-disabled`). Standard `<ul>` / `<li>` attributes (role, aria-*, data-*, handlers) pass through, so a listbox is built by adding the roles:

```jsx
<List role="listbox" aria-label="Plan">
  <ListItem role="option" aria-selected selected>Team</ListItem>
  <ListItem role="option" aria-selected={false}>Free</ListItem>
</List>
```

<Callout type="hint">List owns no selection or focus state — the consumer sets `selected` / `active` and the ARIA attributes the role needs.</Callout>
