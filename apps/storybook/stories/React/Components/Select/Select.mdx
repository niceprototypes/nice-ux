### Usage

```jsx
<Select
  aria-label="Country"
  placeholder="Choose a country"
  options={[
    { value: "nl", label: "Netherlands" },
    { value: "eg", label: "Egypt" },
  ]}
  value={value}
  onChange={setValue}
/>
```
