<Ink>Pass an object to adjust the token's channels. The color stays a token, so it still follows day and night:</Ink>

```tsx
<Icon name="lightning" color={{ name: "highlight", transform: [null, null, 40, null] }} />
```

<Ink>Channels are</Ink>
<Ink code>[hue, saturation, lightness, alpha]</Ink><Ink>. A number sets the channel,</Ink>
<Ink code>"+10"</Ink>
<Ink>and</Ink>
<Ink code>"-10"</Ink>
<Ink>shift it,</Ink>
<Ink code>"*0.5"</Ink>
<Ink>scales it, and</Ink>
<Ink code>null</Ink>
<Ink>leaves it alone.</Ink>
