<StoryDescription property="color">
  Sets the color of the icon using color tokens.
</StoryDescription>

Pass an object to adjust the token's channels. The color stays a token, so it
still follows day and night:

```tsx
<Icon name="lightning" color={{ name: "highlight", transform: [null, null, 40, null] }} />
```

Channels are `[hue, saturation, lightness, alpha]`. A number sets the channel,
`"+10"` and `"-10"` shift it, `"*0.5"` scales it, and `null` leaves it alone.
