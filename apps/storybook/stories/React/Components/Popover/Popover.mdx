## Guide

While `open`, Popover renders in a portal at `<body>` with `position: fixed`, so a scrolling or overflow-hidden ancestor never clips it. It is placed on `position`'s side of `anchorRef`, `align`ed on the cross axis and `popover.offset` away, and the coordinates are recomputed on window scroll (capture phase, so nested scrollers count) and resize.

Popover is controlled. Escape, or a pointerdown outside the popover, the anchor and every `ignoreOutsideRefs` element, calls `onOpenChange(false)`; the popover closes only when `open` turns false. On close, focus returns to the anchor if it was inside the popover. Focus is not trapped.

The surface sets radius, shadow, stacking and max height from the `popover.*` tokens and scrolls content taller than the max height. It has no padding: put a List, or your own layout, inside. The placement math is exported as `computeAnchorPosition` for surfaces that position themselves:

```js
import { computeAnchorPosition } from "nice-react-popover"

computeAnchorPosition(anchor.getBoundingClientRect(), "bottom", "start", 8)
// → { top, left, transform }
```

<Callout type="hint">Pass the trigger in `ignoreOutsideRefs` when it is not the anchor, or its pointerdown dismisses the popover before its own toggle runs.</Callout>
