## RTL page

<Ink color="light">
  Inside an RTL ancestor the whole chrome mirrors: <code>start</code> sits on
  the right, <code>end</code> on the left, and padding follows the inline
  axis.
</Ink>

<DataTableRow
  columns={DEMO_CODE_COLUMNS}
  values={[

  ]}

## dirName

<Ink color="light">
  <code>dirName</code> names a second form field that submits the control's
  resolved direction (<code>ltr</code> / <code>rtl</code>) with the form —
  useful with <code>dir="auto"</code>. It is rendered as the lowercase{" "}
  <code>dirname</code> attribute.
</Ink>
