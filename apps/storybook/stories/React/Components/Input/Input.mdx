<Ink as="h2">Guide</Ink>

<Ink as="span">Input renders a wrapper, the field chrome (border, radius, background, padding, focus ring), around <code>start</code>, the native control and <code>end</code>. <code>className</code> and <code>style</code> apply to the wrapper. <code>ref</code>, <code>id</code>, <code>name</code>, <code>aria-*</code>, <code>data-testid</code> and every native attribute apply to the native control, which stays the focus target. <code>onChange</code> receives the new string value, then the event.</Ink>

```jsx
<Input className="wrapper-class" ref={controlRef} aria-label="Email" />

// <div class="… wrapper-class">
//   <input aria-label="Email" … />   ← controlRef.current
// </div>
```

<Ink as="span"><code>backgroundColor</code> and <code>borderColor</code> take token variants, not CSS colour strings: a <code>BackgroundColorType</code> / <code>BorderColorType</code> name, or an object <code>{"{ name, theme?, breakpoint?, inverse?, transform? }"}</code>. They resolve through the <code>input.backgroundColor</code> and <code>input.borderColor</code> component groups.</Ink>

```jsx
<Input backgroundColor="raised" borderColor="link" />
```

<Ink as="span">The native control draws no outline. When anything inside the chrome has <code>:focus-visible</code> (the control, or a button in a slot), the wrapper draws an outline ring from the <code>input.focusRing</code> tokens; it adds no layout. Pointer focus changes only the border colour.</Ink>

<Ink as="span"><code>start</code> and <code>end</code> sit inside the chrome on the inline-start and inline-end sides, so they mirror in RTL. Input adds no <code>aria-hidden</code>: wrap decorative icons in <code>aria-hidden="true"</code>, and give interactive content such as a clear button its own <code>aria-label</code>.</Ink>

<Ink as="span"><code>width</code> sizes the chrome from the <code>input.width</code> scale. Numeric variants hold that many characters at every <code>size</code>, so the width hints at the expected answer length. <code>full</code> (default) fills the container.</Ink>

<Callout type="hint">`className` and `style` style the wrapper; `ref`, `id` and `aria-*` go to the native control.</Callout>
