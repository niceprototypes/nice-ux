## titleProps

Forwarded to the title's `Typography`. Any prop from `TypographyProps` (except `children`) can be passed.

### titleProps.as

<CodeRow
  fullWidth
  previewCell={
    <Tile
      title="Title"
      description="Description"
      titleProps={{ as: "h1" }}
    />
  }
  language="tsx"
  code={`<Tile\n  title="Title"\n  description="Description"\n  titleProps={{ as: "h1" }}\n/>`}
/>
