## ISO-string contract

<Ink color="light">
  Same contract as <code>Calendar</code>: <code>value</code>,{" "}
  <code>defaultValue</code>, <code>min</code>, <code>max</code> and the{" "}
  <code>onChange</code> argument are ISO <code>YYYY-MM-DD</code> strings;{" "}
  <code>null</code> means empty; a JS <code>Date</code> is never accepted or
  returned. <code>onChange</code> is typed <code>string | null</code>; v1 only
  ever passes a date string.
</Ink>

## Picker

<Ink color="light">
  v1 is picker-only. The visible Input is read-only and shows the value
  formatted with <code>Intl.DateTimeFormat(locale, {"{ dateStyle: \"medium\" }"})</code>.
  The calendar button in Input's <code>end</code> slot (accessible name
  "Choose date") opens a popover anchored to the field, and focus moves to the
  calendar's tabbable day. Selecting a day sets the value and closes the
  popover; Escape or a pointer press outside closes it. Focus returns to the
  field. Typed or segmented entry is not supported yet.
</Ink>
