<Ink as="h2">Guide</Ink>

<Ink as="span">DateField v1 is picker-only. The visible Input is read-only and shows the value formatted with <code>{"Intl.DateTimeFormat(locale, { dateStyle: \"medium\" })"}</code>. The calendar button in Input's <code>end</code> slot (accessible name "Choose date") opens a popover anchored to the field and moves focus to the calendar's tabbable day. Selecting a day sets the value and closes the popover; Escape or a pointer press outside closes it, and focus returns to the field. Typed or segmented entry is not supported yet.</Ink>

<Ink as="span">It uses Calendar's ISO contract: <code>value</code>, <code>defaultValue</code>, <code>min</code>, <code>max</code> and the <code>onChange</code> argument are <code>YYYY-MM-DD</code> strings, and <code>null</code> means empty. <code>onChange</code> is typed <code>string | null</code>; v1 only ever passes a date string. <code>min</code>, <code>max</code>, <code>isDateDisabled</code> and <code>locale</code> are passed to the Calendar, and <code>status="disabled"</code> disables the calendar button.</Ink>

<Ink as="span">Every other Input prop passes through, except <code>as</code>, <code>type</code>, <code>end</code>, <code>value</code>, <code>defaultValue</code>, <code>onChange</code> and <code>name</code>, which DateField owns. <code>name</code> is placed on a hidden input whose value is the ISO date (or <code>""</code> when empty); the visible input has no <code>name</code>.</Ink>

```jsx
<form onSubmit={handleSubmit}>
  <DateField name="start" defaultValue="2026-09-24" />
</form>

// new FormData(form).get("start") → "2026-09-24", not "Sep 24, 2026"
```

<Ink as="span">DateField renders through Input, so inside a <code>Field</code> the visible input takes the Field's id, label, description and error wiring, <code>aria-invalid</code> and <code>required</code> with no extra props. As with Select's combobox, the read-only input and the hidden input are not validated natively: check <code>required</code> in your submit handler and report it through the Field's <code>error</code>.</Ink>

```jsx
<Field label="Start date" error={error} invalid={!!error} required>
  <DateField name="start" status={error ? "error" : "base"} />
</Field>
```

<Callout type="hint">Forms receive the ISO date from the hidden input — never the locale-formatted text in the field.</Callout>
