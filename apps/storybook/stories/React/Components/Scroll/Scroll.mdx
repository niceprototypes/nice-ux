# Scroll

```bash
npm install nice-react-scroll
```

### Setup

```jsx
import { ScrollProvider, Sticky, FadeOnScroll } from "nice-react-scroll"
```

### Usage

```jsx
<ScrollProvider>
  <Sticky>{header}</Sticky>
</ScrollProvider>
```
