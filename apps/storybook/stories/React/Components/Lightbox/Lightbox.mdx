# Lightbox

```bash
npm install nice-react-lightbox
```

### Setup

```jsx
import Lightbox from "nice-react-lightbox"
```

### Usage

```jsx
<Lightbox
  imageUrl="/image.png"
  alt="Description"
>
  {children}
</Lightbox>
```
