## Guide

`nice-react-field` has named exports only, no default export.

Field renders a native `<label>`, the control, an optional description and an
always-mounted polite live region for the error. It publishes the wiring
through context; the control applies it. Input, and everything built on it
(Select, DateField), already does:

- `id` — the control takes the Field's id, so the label's `htmlFor` names it.
  It defaults to `useId()`; pass `id` to fix it.
- `aria-describedby` — ordered `[description, error, own]`. The error id is
  present only while there is an error.
- `aria-invalid="true"` — only while the Field is `invalid`, never `"false"`.
  It changes no style; set `status="error"` on the control.
- `required` — native `required` on the control. The label renders no
  asterisk; mark the other fields with `optionalLabel` instead.

In development, Field warns in the console when no element inside it carries
the id — the silent failure where the label names nothing.

`Fieldset` groups related controls under a native `<fieldset>`. `legend` is
required and names the group; `description` follows it and is referenced by
the fieldset's `aria-describedby`. `disabled` is the native attribute and
disables every control inside.

```jsx
<Fieldset legend="Shipping address" description="Where the order is delivered.">
  <Field label="Street and number"><Input /></Field>
  <Field label="Postcode"><Input width="10" /></Field>
</Fieldset>
```

A custom control reads the wiring with `useField()`, which returns
`{ id, labelId, descriptionId?, errorId?, describedBy?, invalid, required }`,
or `null` outside a Field. `mergeDescribedBy(fieldDescribedBy, own)` joins the
two id lists in order, drops empty entries, keeps the first occurrence of each
id, and returns `undefined` when nothing is left, so no empty attribute
renders.

```jsx
const field = useField()

<input
  id={field?.id}
  aria-describedby={mergeDescribedBy(field?.describedBy, ownDescribedBy)}
  aria-invalid={field?.invalid ? true : undefined}
  required={field?.required}
/>

mergeDescribedBy("f-desc f-err", "hint f-desc") // "f-desc f-err hint"
mergeDescribedBy(undefined, undefined)          // undefined
```

<Callout type="hint">Field only publishes the wiring — the control must apply `id`, `aria-describedby`, `aria-invalid` and `required`. Input does this for you.</Callout>
