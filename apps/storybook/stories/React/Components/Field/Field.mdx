### Setup

```jsx
import { Field, Fieldset, useField, mergeDescribedBy } from "nice-react-field"
```

<Ink color="light">
  Multi-component package: named exports only, no default export.
</Ink>

### Usage

```jsx
<Field label="Email" description="We never share it." error={error} invalid={!!error}>
  <Input type="email" value={email} onChange={setEmail} />
</Field>
```

## Basic

<Ink color="light">
  Field renders a native <code>&lt;label&gt;</code>, the control, an optional
  description, and an always-mounted polite live region for the error. It
  publishes the wiring through context (<code>useField()</code>); the control
  applies it. Input — and everything built on it (Select, DateField) — reads
  the context: it takes the Field's <code>id</code>, merges the description and
  error ids into <code>aria-describedby</code> in the order{" "}
  <code>[description, error, own]</code>, sets <code>aria-invalid="true"</code>{" "}
  only when the Field is <code>invalid</code>, and becomes{" "}
  <code>required</code> when the Field is.
</Ink>
