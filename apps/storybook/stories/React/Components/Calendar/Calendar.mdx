## Guide

`nice-react-calendar` has named exports only (`Calendar`, `DateField`), no
default export.

Dates cross the API only as ISO 8601 `YYYY-MM-DD` strings. `value`,
`defaultValue`, `min`, `max`, the `onChange` argument and the `isDateDisabled`
argument are all ISO strings, and `null` means no selection. A JS `Date` is
never accepted or returned; an invalid string counts as no selection. v1 uses
the Gregorian calendar with UTC arithmetic, so no time zone shifts a date.

```jsx
const [date, setDate] = useState("2026-09-24")

<Calendar value={date} onChange={setDate} min="2026-09-01" />
// onChange("2026-09-25")
```

The first column comes from the locale: `Intl.Locale` week info where the
engine provides it, else a region table (Sunday for regions such as US,
Saturday for regions such as EG, otherwise Monday). `firstDayOfWeek` (0 Sunday … 6 Saturday) overrides it, and
Home / End follow the resolved start.

Direction comes from `useLocale()` in `nice-react-styles`: the `dir` / `locale`
of the nearest `StylesProvider`, else the document's `dir` / `lang`. In RTL,
ArrowRight moves to the previous day and ArrowLeft to the next, following the
visual order, and the month carets swap. The `locale` prop changes labels and
week start, not key direction; the grid mirrors inside a `dir="rtl"` ancestor.

```jsx
<div dir="rtl">
  <StylesProvider locale="ar-EG">
    <Calendar aria-label="التاريخ" />
  </StylesProvider>
</div>
```

The grid follows the ARIA grid pattern with a roving tabindex: one day is
tabbable — the selected day, else today, else the first enabled day of the
visible month.

| Key | Action |
|-----|--------|
| ArrowRight / ArrowLeft | Next / previous day (mirrored in RTL) |
| ArrowDown / ArrowUp | Same weekday next / previous week |
| Home / End | Start / end of the week |
| PageDown / PageUp | Same day next / previous month |
| Shift + PageDown / PageUp | Same day next / previous year |
| Enter / Space | Select the focused day |

Moving focus off the visible month changes the month. Focus stops at `min` and
`max`. Disabled days stay focusable (`aria-disabled`), so the arrows move
across them.

<Callout type="hint">Pass and store ISO `YYYY-MM-DD` strings — Calendar never accepts or returns a `Date`.</Callout>
