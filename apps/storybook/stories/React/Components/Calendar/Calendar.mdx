## ISO-string contract

<Ink color="light">
  Dates cross the API only as ISO 8601 <code>YYYY-MM-DD</code> strings (e.g.{" "}
  <code>"2026-09-24"</code>). <code>value</code>, <code>defaultValue</code>,{" "}
  <code>min</code>, <code>max</code>, the <code>onChange</code> argument and
  the <code>isDateDisabled</code> argument are all ISO strings; a JS{" "}
  <code>Date</code> is never accepted or returned. <code>null</code> means no
  selection. Invalid strings count as no selection. v1 interprets and displays
  dates in the Gregorian calendar, with UTC-based arithmetic, so no time zone
  shifts a date.
</Ink>

## Keyboard

<Ink color="light">
  The month grid follows the ARIA grid pattern with a roving tabindex: one day
  is tabbable — the selected day, else today, else the first enabled day of the
  visible month.
</Ink>

| Key | Action |
|-----|--------|
| ArrowRight / ArrowLeft | Next / previous day (mirrored in RTL) |
| ArrowDown / ArrowUp | Same weekday next / previous week |
| Home / End | Start / end of the week |
| PageDown / PageUp | Same day next / previous month |
| Shift + PageDown / PageUp | Same day next / previous year |
| Enter / Space | Select the focused day |

<Ink color="light">
  Moving focus off the visible month changes the month. Focus stops at{" "}
  <code>min</code> and <code>max</code>. Disabled days stay focusable (
  <code>aria-disabled</code>) so the arrows move across them.
</Ink>

## RTL

<Ink color="light">
  Direction comes from <code>useLocale()</code> in{" "}
  <code>nice-react-styles</code>: the <code>dir</code> / <code>locale</code>{" "}
  props of the nearest <code>StylesProvider</code>, else the document's{" "}
  <code>dir</code> / <code>lang</code>. In RTL, ArrowRight moves to the
  previous day and ArrowLeft to the next (following the visual order), and the
  month-navigation carets swap. The <code>locale</code> prop alone changes
  labels and week start, not key direction; the grid's visual mirroring comes
  from a <code>dir="rtl"</code> ancestor. See the <code>locale</code> page for
  an <code>ar-EG</code> example.
</Ink>
