<Ink as="h2">Guide</Ink>

<Ink as="span"><code>nice-react-calendar</code> has named exports only (<code>Calendar</code>, <code>DateField</code>), no default export.</Ink>

<Ink as="span">Dates cross the API only as ISO 8601 <code>YYYY-MM-DD</code> strings. <code>value</code>, <code>defaultValue</code>, <code>min</code>, <code>max</code>, the <code>onChange</code> argument and the <code>isDateDisabled</code> argument are all ISO strings, and <code>null</code> means no selection. A JS <code>Date</code> is never accepted or returned; an invalid string counts as no selection. v1 uses the Gregorian calendar with UTC arithmetic, so no time zone shifts a date.</Ink>

```jsx
const [date, setDate] = useState("2026-09-24")

<Calendar value={date} onChange={setDate} min="2026-09-01" />
// onChange("2026-09-25")
```

<Ink as="span">The first column comes from the locale: <code>Intl.Locale</code> week info where the engine provides it, else a region table (Sunday for regions such as US, Saturday for regions such as EG, otherwise Monday). <code>firstDayOfWeek</code> (0 Sunday … 6 Saturday) overrides it, and Home / End follow the resolved start.</Ink>

<Ink as="span">Direction comes from <code>useLocale()</code> in <code>nice-react-styles</code>: the <code>dir</code> / <code>locale</code> of the nearest <code>StylesProvider</code>, else the document's <code>dir</code> / <code>lang</code>. In RTL, ArrowRight moves to the previous day and ArrowLeft to the next, following the visual order, and the month carets swap. The <code>locale</code> prop changes labels and week start, not key direction; the grid mirrors inside a <code>dir="rtl"</code> ancestor.</Ink>

```jsx
<div dir="rtl">
  <StylesProvider locale="ar-EG">
    <Calendar aria-label="التاريخ" />
  </StylesProvider>
</div>
```

<Ink as="span">The grid follows the ARIA grid pattern with a roving tabindex: one day is tabbable — the selected day, else today, else the first enabled day of the visible month.</Ink>

<Ink as="span">Moving focus off the visible month changes the month. Focus stops at <code>min</code> and <code>max</code>. Disabled days stay focusable (<code>aria-disabled</code>), so the arrows move across them.</Ink>

<Callout type="hint">Pass and store ISO `YYYY-MM-DD` strings — Calendar never accepts or returns a `Date`.</Callout>
