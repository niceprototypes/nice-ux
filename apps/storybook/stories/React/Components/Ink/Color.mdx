<StoryHeader title="color" />

<StoryDescription property="color">
  Sets the text color using color tokens.
</StoryDescription>

<Ink>Pass an object to adjust the token's channels. The color stays a token, so it still follows day and night:</Ink>

```tsx
<Ink color={{ name: "highlight", transform: [null, null, 40, null] }}>
  Darkened highlight
</Ink>
```

<Ink>Channels are</Ink>
<Ink code>[hue, saturation, lightness, alpha]</Ink><Ink>. A number sets the channel,</Ink>
<Ink code>"+10"</Ink>
<Ink>and</Ink>
<Ink code>"-10"</Ink>
<Ink>shift it,</Ink>
<Ink code>"*0.5"</Ink>
<Ink>scales it, and</Ink>
<Ink code>null</Ink>
<Ink>leaves it alone. Scaling travels better than shifting — a fixed shift that suits the day value can run past the end of the scale at night.</Ink>
