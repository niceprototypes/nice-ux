<Ink as="h2">Principles</Ink>

<Ink as="span"><Ink as="span" weight="semibold">Decentralized by design.</Ink> Every <code>nice-*</code> package is its own repository, versioned, published, and consumable on its own. There is no monorepo and no single codebase — a package depends on its foundations through npm like any other consumer would. Work is scoped to one repository at a time, and a change that appears to need edits across several is a signal to look at the dependency boundary between them.</Ink>

<Ink as="span"><Ink as="span" weight="semibold">The token system is the origin pattern.</Ink> The token generation system in <code>nice-styles</code> — token JSON to generated data, types, and CSS, to runtime getters and setters — is the foundation the rest depend on. A package that cannot reach logic it needs through the token system is a showstopper: stop, report the gap, fix the token system first.</Ink>

<Ink as="span"><Ink as="span" weight="semibold">Alignment.</Ink> Independence is structural; consistency is deliberate. Anything shared — TypeScript version, build config, lint rules — belongs in a foundation package, consumed by every repository at the same version rather than copied into each. Divergence is a defect to fix.</Ink>

<Callout type="hint">Artifacts have fixed homes: an audit report goes to `manifest/.reports/audit/{slug}.md`, a research report to `manifest/.reports/research/{slug}.md`, and a per-package change record to that package's `.nice/bump.md`.</Callout>
