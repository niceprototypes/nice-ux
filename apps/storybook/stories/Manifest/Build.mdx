Files here are topic references: load the one your task or the root index points to. Local packages link by `file:` reference; three non-overlapping `nicely` commands cover the workspace-level concerns.

| File | Contents |
|------|----------|
| `symlinks.md` | nice-toolkit, `file:` references, nice-toolkit CLI usage. |
| `vite.md` | Vite configuration for nice-storybook, nice-vite-watcher. |
| `image-compressor.md` | nice-image-compressor CLI for PNG compression via pngquant. |

```bash
nicely --clean       # kill dev-server ports + wipe consumer build-tool caches
nicely --dedupe      # remove duplicate singletons from linked packages
nicely --build-all   # rebuild every linked package's dist in tier order
```

<Callout type="hint">After dependency changes, run `nicely --dedupe`. After source changes consumers don't see, `nicely --clean`. After a foundation refactor or a fresh clone, `nicely --build-all`. For one foundation package, `nicely --build-icons` rebuilds just nice-icons and its dependents in tier order.</Callout>
