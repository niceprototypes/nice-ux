Override defaults, load a font, and go responsive. The four kinds of code below
are broken down underneath.

```tsx
// App.tsx

import {
  StylesProvider,
  setTokens,
  getToken,
  getBreakpoint,
} from "nice-react-styles"
import styled from "styled-components"
import Ink from "nice-react-ink"
import Button from "nice-react-button"

setTokens({
  breakpoints: {
    tablet: 700,
    laptop: 1100,
  },
  fontFamily: {
    base: "Inter, sans-serif",    // Default override
    heading: "Inter, sans-serif", // Headings read their own token
  },
  fontSize: {
    base: { phone: "16px", "laptop+": "18px" },
    larger: { phone: "32px", "laptop+": "44px" },
  },
} as const)

const Card = styled.div`
  padding: ${getToken("gap", "large")};
  font-family: ${getToken("fontFamily", "base")};

  ${getBreakpoint("laptop+")} {
    padding: ${getToken("gap", "larger")};
  }
`

export default function App() {
  return (
    <StylesProvider googleFonts="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap">
      <Card>
        <Ink as="h1" size="larger">Responsive & branded</Ink>

        {/* An interactive component inherits the same tokens — no extra styling. */}
        <Button status="success" filled iconRight="arrow-right">
          Get started
        </Button>
      </Card>
    </StylesProvider>
  )
}
```

## 1. Token map — <Code code="setTokens" language="tsx" inlined />

Writes overrides, custom tokens, and breakpoint floors to the page as CSS
variables. Run it once, at module load.

- A string is static; an object keyed by breakpoints is responsive. `laptop` is
  one band, `laptop+` is that band and up, `laptop-` is that band and down.
- A band with no key keeps the library default — here, `tablet`.
- Values are emitted as written, so include a fallback font.
- Headings read `fontFamily.heading`, not `base`.

## 2. Styled components — <Code code="getToken" language="tsx" inlined />, <Code code="getBreakpoint" language="tsx" inlined />

`getToken` returns a `var()`, so responsive and themed values follow the
viewport and theme on their own. `getBreakpoint` returns a fixed
`@media` string built when it is called.

- Call `setTokens` first — a `getBreakpoint` evaluated earlier keeps the default
  1280px floor. Keep it in its own module, imported first.
- Unknown token names are compile errors.

## 3. Provider — <Code code="StylesProvider" language="tsx" inlined />

Supplies tokens to nice components and loads fonts. `googleFonts` adds the font
links to `<head>` once.

- Loading a font does not apply it; the `fontFamily` tokens do.
- Request every weight used — `h1`–`h3` render at 700.

## 4. Components — <Code code="Ink" language="tsx" inlined />, <Code code="Button" language="tsx" inlined />

Read the same tokens, so they restyle with no extra CSS. `Ink as="h1"` uses the
heading font and `fontSize.larger`; `Button` inherits `Card`'s font.
