<Ink as="h2">Get breakpoints</Ink>

<Ink>Configure your design for</Ink>
<Ink weight="semibold">different screen sizes and ranges </Ink>
<Ink>by tweaking breakpoint variants for tokens and components, or by using </Ink>
<Ink code>getBreakpoint</Ink>
<Ink> in your style code.</Ink>

<Ink as="h3">CSS only</Ink>

```cssapp
@import "@niceprototypes/styles/tokens.css";

.phone-only {
  font-size: var(--np--font-size--phone);
}
.laptop-only {
  font-size: var(--np--font-size--laptop);
}
.desktop-only {
  font-size: var(--np--font-size--desktop);
}
```

<NewLines />

<Ink as="h3">JS + CSS</Ink>

[//]: # "For CSS-in-JS or runtime CSS strings, `getBreakpoint` returns the matching `@media (min-width: …)` literal sourced from the same threshold table the build uses, so JS and CSS stay in sync:"

```js
import { getBreakpoint, getToken } from "@niceprototypes/styles"

const css = `${getBreakpoint("tablet+")} {
  h1 {
    font-size: ${getToken("fontSize", "larger")};
  }
}`
```

<Callout type="learning">
  Calling `getToken` inside of an instance of `getBreakpoint` will automatically
  resolve to the correct breakpoint variant.
</Callout>

<NewLines />

<Ink as="h3">Styled Components</Ink>

[//]: # "The same `getBreakpoint` literal drops straight into a styled-component, paired with `getToken` for the values — JS and CSS stay on one threshold table:"

<Install
  package="react-styles"
  with="styled-components"
/>

```tsx
import styled from "styled-components"
import { getBreakpoint, getToken } from "@niceprototypes/styles"

const Wrapper = styled.div`
  padding: ${getToken("gap")};

  ${getBreakpoint("laptop+")} {
    padding: ${getToken("gap", "large")};
  }
`
```

<Ink as="h2">Set breakpoints</Ink>

<Ink>Thresholds are the pixel floors each breakpoint starts at. Set them with the</Ink>
<Ink code>breakpoints</Ink>
<Ink>key of</Ink>
<Ink code>setTokens</Ink><Ink>, alongside your tokens. Thresholds apply first, so responsive values in the same call use the new ones:</Ink>

```ts
import { setTokens } from "@niceprototypes/styles"

setTokens({
  breakpoints: { laptop: 1100 },
  gap: { base: { phone: "12px", "laptop+": "20px" } },
})
```

<NewLines />

<Ink as="h3">Breakpoints only</Ink>

<Ink>If a call sets nothing but thresholds,</Ink>
<Ink code>setBreakpoints</Ink>
<Ink>is the shortcut:</Ink>

```ts
import { setBreakpoints } from "@niceprototypes/styles"

setBreakpoints({
  tablet: 700,
  laptop: 1100,
  desktop: 1800,
})
```

<Callout type="hint">`setBreakpoints(values)` is exactly `setTokens({ breakpoints: values })`. Already calling `setTokens`? Add the `breakpoints` key and skip the helper — one call, one source of truth.</Callout>

<NewLines />

<Ink>Both forms take any subset of</Ink>
<Ink code>tablet</Ink><Ink>,</Ink>
<Ink code>laptop</Ink><Ink>, and</Ink>
<Ink code>desktop</Ink><Ink>;</Ink>
<Ink code>phone</Ink>
<Ink>is the base below the first floor and cannot be set. Values must be positive and ascending, or the call throws. Setting a threshold moves every</Ink>
<Ink code>@media</Ink>
<Ink>block that uses it — generated tokens, component overrides, and the values of earlier</Ink>
<Ink code>setTokens</Ink>
<Ink>calls — so</Ink>
<Ink code>getBreakpoint</Ink><Ink>,</Ink>
<Ink code>useBreakpoint</Ink><Ink>, and the CSS stay on one table.</Ink>
