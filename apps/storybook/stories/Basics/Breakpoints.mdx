### JS + CSS

[//]: # "For CSS-in-JS or runtime CSS strings, `getBreakpoint` returns the matching `@media (min-width: …)` literal sourced from the same threshold table the build uses, so JS and CSS stay in sync:"

```js
import { getBreakpoint, getToken } from "nice-styles"

const css = `${getBreakpoint("tablet+")} {
  h1 {
    font-size: ${getToken("fontSize", "larger")};
  }
}`
```

<Callout type="learning">
  Calling `getToken` inside of an instance of `getBreakpoint` will automatically
  resolve to the correct breakpoint variant.
</Callout>

### Styled Components

[//]: # "The same `getBreakpoint` literal drops straight into a styled-component, paired with `getToken` for the values — JS and CSS stay on one threshold table:"

```tsx
import styled from "styled-components"
import { getBreakpoint, getToken } from "nice-react-styles"

const Wrapper = styled.div`
  padding: ${getToken("gap")};

  ${getBreakpoint("laptop+")} {
    padding: ${getToken("gap", "large")};
  }
`
```

## Set breakpoints

Thresholds are the pixel floors each breakpoint starts at. Set them with the `breakpoints` key of `setTokens`, alongside your tokens. Thresholds apply first, so responsive values in the same call use the new ones:

```ts
import { setTokens } from "nice-react-styles"

setTokens({
  breakpoints: { laptop: 1100 },
  gap: { base: { phone: "12px", "laptop+": "20px" } },
})
```

<NewLines />

### Breakpoints only

If a call sets nothing but thresholds, `setBreakpoints` is the shortcut:

```ts
import { setBreakpoints } from "nice-react-styles"

setBreakpoints({
  tablet: 700,
  laptop: 1100,
  desktop: 1800,
})
```

<Callout type="hint">`setBreakpoints(values)` is exactly `setTokens({ breakpoints: values })`. Already calling `setTokens`? Add the `breakpoints` key and skip the helper — one call, one source of truth.</Callout>

<NewLines />

Both forms take any subset of `tablet`, `laptop`, and `desktop`; `phone` is the base below the first floor and cannot be set. Values must be positive and ascending, or the call throws. Setting a threshold moves every `@media` block that uses it — generated tokens, component overrides, and the values of earlier `setTokens` calls — so `getBreakpoint`, `useBreakpoint`, and the CSS stay on one table.
