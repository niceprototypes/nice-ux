<Ink as="h2">Get fonts</Ink>

<Ink>You have the freedom to</Ink>
<Ink weight="semibold">use vendor fonts or local font files</Ink>
<Ink>for your project.</Ink>

<NewLines />

<Ink as="h3">Google</Ink>

```ts
import { injectFonts } from "@niceprototypes/styles"

injectFonts({ googleFonts: "https://fonts.googleapis.com/…" })
```

<Ink>Output:</Ink>

```html
<link data-nice-font="" rel="preconnect" href="https://fonts.googleapis.com">
<link data-nice-font="" rel="preconnect" href="https://fonts.gstatic.com" crossorigin="anonymous">
<link data-nice-font="" rel="stylesheet" href="https://fonts.googleapis.com/…">
```

<NewLines />

<Ink as="h3">Adobe</Ink>

```ts
import { injectFonts } from "@niceprototypes/styles"

injectFonts({ adobeFonts: "https://use.typekit.net/…" })
```

<Ink>Output:</Ink>

```html
<link data-nice-font="" rel="preconnect" href="https://use.typekit.net">
<link data-nice-font="" rel="preconnect" href="https://p.typekit.net" crossorigin="anonymous">
<link data-nice-font="" rel="stylesheet" href="https://use.typekit.net/…">
```

<NewLines />

<Ink as="h3">Custom fonts</Ink>

<Ink>Use the</Ink>
<Ink code>injectFonts</Ink>
<Ink>function to inject preconnects and stylesheets for your font family:</Ink>

```ts
import { injectFonts } from "@niceprototypes/styles"

injectFonts({
  links: [
    { rel: "preconnect", href: "https://cdn.example.com" },
    { rel: "stylesheet", href: "https://cdn.example.com/font.css" },
  ],
})
```

<Ink>Output:</Ink>

```html
<link data-nice-font="" rel="preconnect" href="https://cdn.example.com">
<link data-nice-font="" rel="stylesheet" href="https://cdn.example.com/font.css">
```

<Line />

<Ink as="h2">Set fonts</Ink>

<Ink as="h3">1. Set tokens</Ink>

<Install package="styles" />

<Ink>Call</Ink>
<Ink code>setTokens</Ink>
<Ink>once on module load, from its own</Ink>
<Ink code>tokens.ts</Ink><Ink>:</Ink>

```tsx
// tokens.ts

import { setTokens } from "@niceprototypes/styles"

setTokens({
  fontFamily: {
    base: "'Google Sans', sans-serif",
  },
})
```

<NewLines />

<Ink as="h3">2. Get tokens</Ink>

<Ink>Use props on</Ink>
<Ink code>StylesProvider</Ink>
<Ink>to inject and control fonts for your React project:</Ink>

<NewLines />

<Ink as="h4">Google</Ink>

```tsx
import { StylesProvider } from "@niceprototypes/styles"
import App from "./App"
import "./tokens" // runs setTokens once on load

<StylesProvider googleFonts="https://fonts.googleapis.com/…">
  <App />
</StylesProvider>
```

<NewLines />

<Ink as="h4">Adobe</Ink>

```tsx
import { StylesProvider } from "@niceprototypes/styles"
import App from "./App"
import "./tokens" // runs setTokens once on load

<StylesProvider adobeFonts="https://use.typekit.net/…">
  <App />
</StylesProvider>
```

<NewLines />

<Ink as="h4">Custom</Ink>

```tsx
import { StylesProvider } from "@niceprototypes/styles"
import App from "./App"
import "./tokens" // runs setTokens once on load

<StylesProvider
  links={[
    { rel: "preconnect", href: "https://cdn.example.com" },
    { rel: "stylesheet", href: "https://cdn.example.com/font.css" },
  ]}
>
  <App />
</StylesProvider>
```
