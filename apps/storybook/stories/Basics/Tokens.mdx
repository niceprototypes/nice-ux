<Ink>Using the tokens in JS allows you to</Ink>

<Ink as="h3">JS only</Ink>

<Ink>Use the</Ink>
<Ink code>getToken</Ink>
<Ink>function and CSS variables provided by</Ink>
<Ink code>@niceprototypes/styles</Ink>
<Ink>for vanilla JS:</Ink>

<Install
  package="styles"
/>

```js
import { getToken } from "@niceprototypes/styles"
import "@niceprototypes/styles/tokens.css"

// Create HTML element
const card = document.createElement("div")

// Apply token values
card.style.padding = getToken("gap", "large")
card.style.backgroundColor = getToken("backgroundColor")
card.style.borderRadius = getToken("borderRadius", "small")

// Append element to DOM
document.body.append(card)
```

<Ink as="h2">Set tokens</Ink>

<Ink>Override default values, create new tokens, or even create new modules. You have</Ink>
<Ink weight="semibold">complete creative control</Ink>
<Ink>with the token setter function.</Ink>

<Ink as="h3">1. Wrap subtree with provider</Ink>

<Ink code>App</Ink>
<Ink>can now consume the tokens:</Ink>

```tsx
import { StylesProvider } from "@niceprototypes/styles"
import "../tokens.ts"
import "../App"

<StylesProvider>
  <App />
</StylesProvider>
```

<NewLines />

<Ink as="h3">2. Call the setter function</Ink>

<Ink>Call</Ink>
<Ink code>setTokens</Ink>
<Ink>once on module load:</Ink>

```ts
import { setTokens } from "@niceprototypes/styles"

setTokens({
  // Static module
  fontSize: {
    base: "18px", // Static token
    jumbo: "96px", // Custom token
  },
  // Custom module
  accentColor: {
    primary: "#dc0000",
    secondary: "#1a1a1a",
  },
} as const)
```

<Callout type="hint">Modules and tokens can be modified (static) or created (custom) in the same object.</Callout>

<NewLines />

<Ink as="h3">3. Access new tokens</Ink>

<Ink>New tokens can be accessed by the getter function:</Ink>

```tsx
import { getToken } from "@niceprototypes/styles"

const Card = ({ children }) => (
  <div
    style={{
      fontSize: getToken("fontSize", "jumbo"),
      color: getToken("accentColor", "primary"),
    }}
  >
    {children}
  </div>
)
```

<Ink as="h2">Transform a color</Ink>

<Ink>Adjust a token's channels without leaving the token system. The result is still a token underneath, so it keeps following day and night:</Ink>

```tsx
import { getToken } from "@niceprototypes/styles"

getToken("color:highlight", { transform: [null, null, 40, null] })
// hsl(from var(--np--color--highlight) h s 40)
```

<Ink>Channels are</Ink>
<Ink code>[hue, saturation, lightness, alpha]</Ink><Ink>:</Ink>

<DataTable
  columns={[{ key: "c0", header: "Entry" }, { key: "c1", header: "Does" }]}
  tables={[{ rows: [
    { id: "0", values: [<Ink><code>null</code></Ink>, <Ink>leaves the channel alone</Ink>] },
    { id: "1", values: [<Ink><code>40</code></Ink>, <Ink>sets it</Ink>] },
    { id: "2", values: [<Ink><code>"+10"</code> / <code>"-10"</code></Ink>, <Ink>shifts it</Ink>] },
    { id: "3", values: [<Ink><code>"*0.5"</code></Ink>, <Ink>scales it</Ink>] },
  ] }]}
/>

<Callout type="hint">Scaling travels better than shifting. A shift sized for the day value can run off the end of the scale at night, where the same token is already dark.</Callout>
