### Use tokens directly

Import the stylesheet and reference the tokens:

<Install
  package="styles"
/>

<NewLines />

```css
@import "nice-styles/tokens.css";

.message {
  color: var(--np--color);

  &.success {
    color: var(--np--color--success);
  }

  &.error {
    color: var(--np--color--error);
  }
}
```

You may choose to alias the Nice UI tokens you need, and use your aliases everywhere else:

    color: var(--color--error);
  }

## JavaScript

Using the tokens in JS allows you to **restructure the token architecture** according to your needs, and easily tweak token values with useful helper functions.

### JS only

Use the `getToken` function and CSS variables provided by `nice-styles` for vanilla JS:

<Install
  package="styles"
/>

<NewLines />

```js
import { getToken } from "nice-styles"
import "nice-styles/tokens.css"

// Create HTML element
const card = document.createElement("div")

// Apply token values
card.style.padding = getToken("gap", "large")
card.style.backgroundColor = getToken("backgroundColor")
card.style.borderRadius = getToken("borderRadius", "small")

// Append element to DOM
document.body.append(card)
```

<NewLines />

### React only

Create and style a React component with tokens:

<Install
  package="react-styles"
/>

<NewLines />

```tsx
import { getToken } from "nice-react-styles"

export default function Card({ children }) {
  return (
    <div
      style={{
        padding: getToken("gap", "large"),
        backgroundColor: getToken("backgroundColor"),
        borderRadius: getToken("borderRadius", "small"),
      }}
    >
      {children}
    </div>
  )
}
```

Then, render the React component inside `StylesProvider`:

```tsx
import { StylesProvider } from "nice-react-styles"

<NewLines />

export default function App() {
  return (
    <StylesProvider>
      <Card>…</Card>
    </StylesProvider>
  )
}
```

<NewLines />

### React + Styled Components

Create and style a Styled Component with tokens:

<Install
  package="react-styles"
  with="styled-components"
/>

<NewLines />

```tsx
// Card.tsx

import { getToken } from "nice-react-styles"
import styled from "styled-components"

const Card = styled.div`
  padding: ${getToken("gap", "large")};
  background-color: ${getToken("backgroundColor")};
  border-radius: ${getToken("borderRadius", "small")};
`

export default Card
```

Render the Styled Component inside `StylesProvider`:

```tsx
import { StylesProvider } from "nice-react-styles"
import styled from "styled-components"
import Card from "./Card"

export default function App() {
  return (
    <StylesProvider>
      <Page>
        <Card>…</Card>
      </Page>
    </StylesProvider>
  )
}
```

## Set tokens

Override default values, create new tokens, or even create new modules. You have **complete creative control** with the token setter function.

### 1. Wrap subtree with provider

`App` can now consume the tokens:

```tsx
import { StylesProvider } from "nice-react-styles"
import "../tokens.ts"
import "../App"

<StylesProvider>
  <App />
</StylesProvider>
```

<NewLines />

### 2. Call the setter function

Call `setTokens` once on module load:

```ts
import { setTokens } from "nice-react-styles"

setTokens({
  // Static module
  fontSize: {
    base: "18px", // Static token
    jumbo: "96px", // Custom token
  },
  // Custom module
  accentColor: {
    primary: "#dc0000",
    secondary: "#1a1a1a",
  },
} as const)
```

<Callout type="hint">Modules and tokens can be modified (static) or created (custom) in the same object.</Callout>

<NewLines />

### 3. Access new tokens

New tokens can be accessed by the getter function:

```tsx
import { getToken } from "nice-react-styles"

const Card = ({ children }) => (
  <div
    style={{
      fontSize: getToken("fontSize", "jumbo"),
      color: getToken("accentColor", "primary"),
    }}
  >
    {children}
  </div>
)
```

## Transform a color

Adjust a token's channels without leaving the token system. The result is still
a token underneath, so it keeps following day and night:

```tsx
import { getToken } from "nice-react-styles"

getToken("color:highlight", { transform: [null, null, 40, null] })
// hsl(from var(--np--color--highlight) h s 40)
```

Channels are `[hue, saturation, lightness, alpha]`:

| Entry | Does |
| --- | --- |
| `null` | leaves the channel alone |
| `40` | sets it |
| `"+10"` / `"-10"` | shifts it |
| `"*0.5"` | scales it |

<Callout type="hint">Scaling travels better than shifting. A shift sized for the day value can run off the end of the scale at night, where the same token is already dark.</Callout>

<NewLines />

Components take the same object on their color props:

```tsx
<Ink color={{ name: "highlight", transform: [null, null, 40, null] }}>
  Darkened highlight
</Ink>
```
