React hooks exposed by `nice-react-styles`. Both read state that
`StylesProvider` publishes through context — one shared instance for the whole
tree, no separate provider to wire.

---

### Contents

- [useBreakpoint](/docs/bindings-usebreakpoint--docs) — Returns the current
  viewport breakpoint name (`"phone"` / `"tablet"` / `"laptop"` / `"desktop"`)
  and re-renders on band changes. Needs no `StylesProvider`. For swapping
  component trees; prefer CSS / the `breakpoints` prop for styling.

- [useDevice](/docs/bindings-usedevice--docs) — Reads the shared
  `{ isMobile }` published by `StylesProvider` when given `detectDevice`. One
  mobile-detection instance for the whole tree (user-agent + touch + viewport,
  with `?mobile=true` / localStorage debug overrides).

- [useTheme](/docs/bindings-usetheme--docs) — Reads the shared `{ theme }`
  published by `StylesProvider` when given `detectTheme`, following the OS
  color-scheme preference.
