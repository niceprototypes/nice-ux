<StoryHeader title="Bindings" />

<Ink as="span">React hooks exposed by <code>nice-react-styles</code>. Both read state that <code>StylesProvider</code> publishes through context — one shared instance for the whole tree, no separate provider to wire.</Ink>

<Line />

<Ink as="h3">Contents</Ink>

<ul>
  <li><Ink as="span"><a href="/?path=/docs/bindings-usebreakpoint--docs" target="_top">useBreakpoint</a> — Returns the current</Ink></li>
</ul>
  viewport breakpoint name (`"phone"` / `"tablet"` / `"laptop"` / `"desktop"`)
  and re-renders on band changes. Needs no `StylesProvider`. For swapping
  component trees; prefer CSS / the `breakpoints` prop for styling.

<ul>
  <li><Ink as="span"><a href="/?path=/docs/bindings-usedevice--docs" target="_top">useDevice</a> — Reads the shared</Ink></li>
</ul>
  `{ isMobile }` published by `StylesProvider` when given `detectDevice`. One
  mobile-detection instance for the whole tree (user-agent + touch + viewport,
  with `?mobile=true` / localStorage debug overrides).

<ul>
  <li><Ink as="span"><a href="/?path=/docs/bindings-usetheme--docs" target="_top">useTheme</a> — Reads the shared <code>{"{ theme }"}</code></Ink></li>
</ul>
  published by `StylesProvider` when given `detectTheme`, following the OS
  color-scheme preference.
