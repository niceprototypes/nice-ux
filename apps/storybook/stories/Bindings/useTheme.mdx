<Ink as="h2">Read it anywhere below</Ink>

<Ink code>useTheme()</Ink>
<Ink>returns the theme</Ink>
<Ink weight="semibold">name</Ink><Ink>. When a component only cares whether it's dark, derive a local</Ink>
<Ink code>isNight</Ink>
<Ink>from it — it's a one-liner, and not every consumer needs it, so the hook stays name-based:</Ink>

```tsx
  const { theme } = useTheme()
  const isNight = theme === "night"

  // append "-dark" to the asset when the night theme is active
  return <img src={`/logo${isNight ? "-dark" : ""}.svg`} alt="Logo" />
}
```

<Ink code>isNight</Ink>
<Ink>local rather than baking it into the hook means branching on</Ink>
<Ink code>theme</Ink>
<Ink>survives adding more themes later, while dark-only consumers still get a clean boolean.</Ink>
