<Ink>Returns the current viewport breakpoint name —</Ink>
<Ink code>"phone"</Ink><Ink>,</Ink>
<Ink code>"tablet"</Ink><Ink>,</Ink>
<Ink code>"laptop"</Ink><Ink>, or</Ink>

<Ink>directly via</Ink>

<Ink as="h2">Usage</Ink>

```tsx
import { useBreakpoint } from "nice-react-styles"

function Gallery() {
  const bp = useBreakpoint()
  return bp === "phone" ? <Carousel /> : <Grid />
}
```

<Ink code>BreakpointName</Ink>
<Ink>is</Ink>
<Ink code>"phone" | "tablet" | "laptop" | "desktop"</Ink><Ink>, smallest to largest. The breakpoint constants are exported too:</Ink>

```tsx

const bp = useBreakpoint()
const wide = bp === BREAKPOINT_DESKTOP
```

<Ink>runs in JS, so it carries costs the CSS layer doesn't:</Ink>
