<StoryHeader title="useDevice" />

Reads the mobile state published by `StylesProvider`. Returns `{ isMobile }`.
When `StylesProvider` is given `detectDevice`, it runs detection once and shares
the result through context — so every descendant reads one shared value, with no
separate provider to wire and no per-component detection. This is the only
device binding; detection lives inside `nice-react-styles`.

<HorizontalRule />

## Enable detection on the provider

```tsx
import { StylesProvider } from "nice-react-styles"

<StylesProvider detectDevice>
  <App />
</StylesProvider>
```

`detectDevice` defaults to `false`. When off, no detection runs and no resize
listener is registered — `useDevice()` returns `{ isMobile: false }`.

## Read it anywhere below

```tsx
import { useDevice } from "nice-react-styles"

function Nav() {
  const { isMobile } = useDevice()
  return isMobile ? <HamburgerMenu /> : <FullNavBar />
}
```

No prop drilling — every component under the `StylesProvider` reads the same
`isMobile` directly.

<HorizontalRule />

## What detection checks

`detectDevice` runs detection once and keeps it current on resize / orientation /
DevTools-emulation changes — a single shared listener for the whole tree. A
viewport is mobile when the user-agent matches a known mobile identifier, **or**
the device has touch and a viewport ≤ 640px (the phone band). Debug overrides
force mobile on: `?mobile=true` in the URL, or
`localStorage.setItem("debug-mobile", "true")`.
