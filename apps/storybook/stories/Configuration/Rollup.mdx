```js
import { createConfiguration } from "@niceprototypes/config-rollup"
```

<Ink as="h3">Usage</Ink>

```js
export default createConfiguration({ plugins: [...] })
```

<Line />

<Ink as="h2">createConfiguration</Ink>

<Ink>Creates a complete rollup configuration with sensible defaults for nice-* packages. Outputs both CJS and ESM formats with sourcemaps. All plugins are included by default.</Ink>

```typescript
// rollup.config.js
import { createConfiguration } from "@niceprototypes/config-rollup"

// Basic usage - uses all defaults
export default createConfiguration()

// With options
export default createConfiguration({
  input: "src/index.ts",
  additionalExternals: ["lodash"],
  bundlePackages: ["@niceprototypes/icon/svg"],
})
```

<Ink as="h4">Options</Ink>

```typescript
{
  input?: string              // Entry point (default: "src/index.ts")
  tsconfig?: string           // Path to tsconfig (default: "./tsconfig.json")
  output?: object             // Custom output config (merged with defaults)
  plugins?: Function[]        // Override default plugins (escape hatch)
  additionalExternals?: string[]   // Extra packages to externalize
  bundlePackages?: string[]   // nice-* packages to bundle instead of externalize
  dts?: boolean               // Generate declaration bundle (default: true)
  dtsInput?: string           // Custom dts input (default: "dist/types/index.d.ts")
}
```

<Ink as="h4">Default Plugins</Ink>

<Ink>The following plugins are included automatically:</Ink>

```text
• rollup-plugin-peer-deps-external
• @rollup/plugin-node-resolve (browser: true)
• @rollup/plugin-commonjs
• @rollup/plugin-typescript
• rollup-plugin-dts (for declaration bundling)
```

<Line />

<Ink as="h2">isNiceExternal</Ink>

<Ink>Pattern-based external detection that automatically externalizes all nice-* packages, React ecosystem, and styled-components. Handles subpath imports like CSS files.</Ink>

```typescript
import { isNiceExternal } from "@niceprototypes/config-rollup"

// Returns true for:
isNiceExternal("@niceprototypes/styles")           // nice-* packages
isNiceExternal("@niceprototypes/styles/tokens.css")  // subpath imports
isNiceExternal("react")                 // React
isNiceExternal("react-dom")             // React DOM
isNiceExternal("styled-components")     // styled-components

// Returns false for:
isNiceExternal("lodash")                // other packages
```

<Ink as="h4">Manual Usage</Ink>

<Ink>If you need custom rollup config, use</Ink>
<Ink code>isNiceExternal</Ink>
<Ink>directly:</Ink>

```typescript
// rollup.config.js
import { isNiceExternal } from "@niceprototypes/config-rollup"

export default {
  input: "src/index.ts",
  output: [...],
  plugins: [...],
  external: isNiceExternal
}
```

<Line />

<Ink as="h2">Watch Mode Configuration</Ink>

<Ink>The configuration includes optimized watch settings that prevent file caching issues during local development. This ensures changes appear immediately without delay.</Ink>

```typescript
// Included automatically in createConfiguration()
{
  cache: false,  // Disable rollup internal caching
  watch: {
    buildDelay: 200,  // Debounce rapid changes
    clearScreen: false,
    chokidar: {
      awaitWriteFinish: {
        stabilityThreshold: 150,
        pollInterval: 50
      },
      usePolling: true,
      interval: 100
    }
  }
}
```

<Ink as="h4">Why These Settings?</Ink>

<Ink>Without these settings, rollup's watch mode can exhibit an "off by one" caching bug where file changes appear one save behind. The</Ink>
<Ink code>awaitWriteFinish</Ink>
<Ink>option ensures files are fully written to disk before rollup reads them, and</Ink>
<Ink code>usePolling</Ink>
<Ink>provides more reliable file change detection on macOS.</Ink>

<Line />

<Ink as="h2">createExternals</Ink>

<Ink>Creates an external function with additional packages or bundle overrides.</Ink>

```typescript
import { createExternals } from "@niceprototypes/config-rollup"

// Add extra packages to externalize
const external = createExternals({
  additional: ["lodash", "date-fns"],
})

// Bundle specific nice-* packages instead of externalizing
const external = createExternals({
  bundle: ["@niceprototypes/icon/svg"],
})

// Both options together
const external = createExternals({
  additional: ["lodash"],
  bundle: ["@niceprototypes/icon/svg"],
})

export default {
  input: "src/index.ts",
  output: [...],
  plugins: [...],
  external
}
```

<Ink>Note: Legacy array format is still supported for backwards compatibility.</Ink>
