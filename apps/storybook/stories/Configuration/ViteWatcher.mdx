<Ink as="h2">The Problem</Ink>

<Ink>When developing with</Ink>
<Ink code>npm link</Ink>
<Ink>or</Ink>
<Ink code>file:</Ink>
<Ink>dependencies, Vite's dev server doesn't detect changes in linked packages. You're forced to restart the dev server every time you modify a linked package.</Ink>

<Ink as="h4">The Solution</Ink>

<Ink>This plugin watches the dist folder of linked packages and triggers a browser reload when they rebuild.</Ink>

```text
Developer edits source
       ↓
Package build runs
       ↓
dist/ updates
       ↓
Plugin detects change (debounced)
       ↓
Browser reloads
```

<Ink as="h4">Vite Only</Ink>

<Ink>This plugin is for Vite projects (including Storybook with Vite). For webpack/CRA projects, use</Ink>
<Ink code>@niceprototypes/toolkit --dev --watch</Ink>
<Ink>instead.</Ink>

<Line />

<Ink as="h2">viteWatcher</Ink>

<Ink>Creates the Vite plugin that watches linked package dist folders.</Ink>

```typescript
// vite.config.ts
import { defineConfig } from 'vite'
import { viteWatcher } from '@niceprototypes/vite-watcher'

export default defineConfig({
  plugins: [
    viteWatcher({
      packages: {
        '@niceprototypes/button': '/Users/me/Code/nice-react-button',
        '@niceprototypes/icon': '/Users/me/Code/nice-react-icon',
      },
      verbose: true,
    }),
  ],
})
```

<Ink as="h4">Options</Ink>

```typescript
{
  packages: Record<string, string>  // Package name → local path
  watchDir?: string                 // Subdirectory to watch (default: 'dist')
  verbose?: boolean                 // Log changes (default: false)
  debounce?: number                 // Debounce delay in ms (default: 300)
}
```

<Line />

<Ink as="h2">getSourceAliases</Ink>

<Ink>Generates Vite resolve aliases pointing to package source files. Use this for packages without special build transforms to get true HMR with state preservation.</Ink>

```typescript
import { getSourceAliases } from '@niceprototypes/vite-watcher'

const linkedPackages = {
  '@niceprototypes/button': '/Users/me/Code/nice-react-button',
  '@niceprototypes/icon': '/Users/me/Code/nice-react-icon',
}

// Only alias packages that don't need build transforms
const aliases = getSourceAliases(
  linkedPackages,
  ['@niceprototypes/button'],  // These get aliased to src/
  'index.ts'              // Entry point (default)
)

// Result:
// { '@niceprototypes/button': '/Users/me/Code/nice-react-button/src/index.ts' }
```

<Line />

<Ink as="h2">Combining Both Approaches</Ink>

<Ink>For the best experience, use source aliases for simple packages (true HMR) and dist watching for packages with build transforms (SVGR, PostCSS, etc.).</Ink>

```typescript
// vite.config.ts
import { defineConfig } from 'vite'
import { viteWatcher, getSourceAliases } from '@niceprototypes/vite-watcher'

const linkedPackages = {
  '@niceprototypes/button': '/Users/me/Code/nice-react-button',
  '@niceprototypes/icon': '/Users/me/Code/nice-react-icon',  // Uses SVGR
  '@niceprototypes/flex': '/Users/me/Code/nice-react-flex',
}

// Packages without special build transforms
const sourceAliasable = ['@niceprototypes/button', '@niceprototypes/flex']

export default defineConfig({
  plugins: [
    viteWatcher({
      packages: linkedPackages,
      verbose: true,
    }),
  ],
  resolve: {
    alias: getSourceAliases(linkedPackages, sourceAliasable),
  },
  optimizeDeps: {
    exclude: Object.keys(linkedPackages),
  },
})
```

<Ink as="h4">Strategy Comparison</Ink>

```text
| Package Type              | Strategy        | HMR Behavior          |
|---------------------------|-----------------|----------------------|
| Simple TypeScript/React   | Source alias    | True HMR (state kept)|
| Uses SVGR, PostCSS, etc.  | Dist watching   | Full reload          |
```

<Line />

<Ink as="h2">Storybook Integration</Ink>

<Ink>Works with Storybook's Vite builder via</Ink>
<Ink code>viteFinal</Ink>
<Ink>config.</Ink>

```typescript
// .storybook/main.ts
import { viteWatcher, getSourceAliases } from '@niceprototypes/vite-watcher'

const linkedPackages = {
  '@niceprototypes/button': '../react-button',
}

const config: StorybookConfig = {
  framework: '@storybook/react-vite',
  viteFinal: async (config) => {
    config.plugins = [
      ...(config.plugins || []),
      viteWatcher({
        packages: linkedPackages,
        verbose: true,
      }),
    ]
    config.resolve = config.resolve || {}
    config.resolve.alias = {
      ...(config.resolve.alias || {}),
      ...getSourceAliases(linkedPackages, Object.keys(linkedPackages)),
    }
    return config
  },
}
```

<Ink as="h2">Limitations</Ink>

<Ink as="h4">Full Page Reload</Ink>

<Ink>Packages watched via dist (not source-aliased) trigger full reloads, not granular HMR. This resets React component state.</Ink>

<Ink as="h4">Build Pipeline Delay</Ink>

<Ink>You need to wait for the linked package's build to complete before changes appear. Run the package in watch mode for faster iteration.</Ink>

```bash
# In the linked package directory
npm run dev  # or npm run build --watch
```

<Ink as="h4">Why Not Source Aliases for Everything?</Ink>

<Ink>Source aliases bypass the package's build pipeline, which breaks packages using:</Ink>

```text
• SVGR — transforms SVG imports to React components
• PostCSS/Tailwind — processes CSS
• Custom Babel plugins — transforms code
• Asset processing — handles images, fonts
```
