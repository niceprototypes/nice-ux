<Ink as="h2">React Jest Configuration</Ink>

<Ink>Complete Jest configuration for React components with TypeScript support. Uses ts-jest for native TypeScript compilation.</Ink>

```typescript
// jest.config.js
export { default } from "@niceprototypes/config-jest/react"
```

<Ink as="h4">Included Configuration</Ink>

```typescript
{
  preset: "ts-jest",
  testEnvironment: "jsdom",
  moduleFileExtensions: ["ts", "tsx", "js", "jsx"],
  testMatch: ["**/*.test.ts", "**/*.test.tsx"],
  transform: {
    "^.+\\.(ts|tsx|js|jsx)$": ["ts-jest", { useESM: true }]
  },
  transformIgnorePatterns: [
    "node_modules/(?!(nice-[^/]+)/)"
  ],
  extensionsToTreatAsEsm: [".ts", ".tsx"],
  moduleNameMapper: {
    "^(\\.{1,2}/.*)\\.js$": "$1",
    "^.+\\.(css|less|scss|sass)$": "<rootDir>/__mocks__/styleMock.js"
  },
  setupFilesAfterEnv: ["@testing-library/jest-dom"]
}
```

<Ink as="h4">Peer Dependencies</Ink>

<Ink>Install the required peer dependencies:</Ink>

```bash
npm install -D jest ts-jest jest-environment-jsdom @testing-library/jest-dom
```

<Line />

<Ink as="h2">CSS Mock</Ink>

<Ink>Empty module export for mocking CSS imports in Jest tests. Referenced by the React config's moduleNameMapper.</Ink>

```typescript
// __mocks__/styleMock.js
module.exports = {}
```

<Ink>This mock is automatically configured in the React Jest config. Create the file at</Ink>
<Ink code>__mocks__/styleMock.js</Ink>
<Ink>in your project root.</Ink>

<Ink as="h4">Alternative: Direct Import</Ink>

<Ink>You can also import the mock directly if you customize your Jest config:</Ink>

```typescript
// jest.config.js
export default {
  moduleNameMapper: {
    "^.+\\.(css|scss)$": "@niceprototypes/config-jest/css-mock"
  }
}
```
