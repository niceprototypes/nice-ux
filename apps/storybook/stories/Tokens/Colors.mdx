## transformColor

These adjust a colour's channels and return a static `hsla()` — the value is
computed once, so it does not follow day and night. For a colour that keeps
following the theme, pass the same channels to `getToken`:

```tsx
getToken("color:error", { transform: [null, null, "*0.5", null] })
// hsl(from var(--np--color--error) h s calc(l * 0.5))
```

Channels are `[hue, saturation, lightness, alpha]`. A number sets the channel,
`"+30"` and `"-30"` shift it, `"*0.5"` scales it, and `null` leaves it alone.
