npm install nice-styles

### Setup

```js
import { getBreakpoint, getBreakpointValue } from "nice-styles"
```

### Usage

```js
getBreakpointValue("phone")   // → 640
getBreakpoint("phone")   // → "@media (max-width: 640px)"
getBreakpoint("tablet")  // → "@media (min-width: 641px)"
getBreakpoint("laptop")  // → "@media (min-width: 1280px)"
getBreakpoint("desktop") // → "@media (min-width: 1720px)"
```

---

## Breakpoint values

<div>

## Usage in styled-components

```typescript
const Box = styled.div`
  background: blue;

  ${getBreakpoint("tablet")} {
    background: orange;
  }

  ${getBreakpoint("laptop")} {
    background: green;
  }

  ${getBreakpoint("desktop")} {
    background: purple;
  }
`
```
