# Responsive

```bash
npm install nice-styles
```

### Setup

```js
import { getBreakpoint } from "nice-styles"
```

### Usage

```js
getBreakpoint("phone").value   // → 640
getBreakpoint("phone").query   // → "@media (max-width: 640px)"
getBreakpoint("tablet").query  // → "@media (min-width: 641px)"
getBreakpoint("laptop").query  // → "@media (min-width: 1280px)"
getBreakpoint("desktop").query // → "@media (min-width: 1720px)"
```

## Breakpoint values

<div>
