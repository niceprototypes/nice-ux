# Responsive

```bash
npm install nice-styles
```

### Setup

```js
import { getBreakpoint } from "nice-styles"
```

### Usage

```js
getBreakpoint("small").value // → 640
getBreakpoint("small").query // → "@media (max-width: 640px)"
getBreakpoint("medium").query // → "@media (min-width: 641px)"
getBreakpoint("large").query // → "@media (min-width: 1280px)"
```

---

## Breakpoint values

<div>
  {breakpoints.map(({ name, query }) => (
    <DocsRow
      key={name}
      previewCell={
        <Typography>{name}</Typography>
      }
      language="css"
      code={query}
    />
  ))}
</div>
