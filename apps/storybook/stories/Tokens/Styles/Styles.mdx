# Tokens

**No framework required.** Install `nice-styles` to get a complete token system
built on CSS custom properties. Works with any stack that renders HTML — static
sites, server-rendered pages, vanilla JS, or as a shared foundation across
frameworks.

```bash
npm install nice-styles
```

Use `--np--` prefixed CSS variables directly in your stylesheets. No runtime,
no build step, no opinions about your component model.

- [Responsive](/docs/tokens-responsive--docs) — Breakpoints and media query helpers

## animationDuration

<div>
  {[
    { name: "base", backgroundColor: getToken("foregroundColor", "error").var },
    {
      name: "slow",
      backgroundColor: getToken("foregroundColor", "warning").var,
    },
  ].map(({ name, backgroundColor }) => {
    const animationName = name === "base" ? "slide" : "slideSlow"
    return (
      <DocsRow
        previewCell={
          <Flex
            style={{
              width: "120px",
              backgroundColor: getToken("backgroundColor", "dark").var,
              borderRadius: `calc(${getToken("cellHeight", "smaller").var} / 2)`,
            }}
          >
            <Flex
              style={{
                backgroundColor,
                width: getToken("cellHeight", "smaller").var,
                height: getToken("cellHeight", "smaller").var,
                borderRadius: `calc(${getToken("cellHeight", "smaller").var} / 2)`,
                animation: `${animationName} calc(${getToken("animationDuration", name).var} * 6) ${getToken("animationEasing").var} infinite`,
                animationDelay:
                  name === "base" ? getToken("animationDuration", name).var : 0,
              }}
            />
          </Flex>
        }
        language="tsx"
        code={`getToken("animationDuration", "${name}").var`}
      />
    )
  })}
</div>
