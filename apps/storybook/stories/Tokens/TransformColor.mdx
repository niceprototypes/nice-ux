  },

<Ink as="span">These adjust a colour's channels and return CSS relative colour syntax over the token's variable, so the result keeps following day and night. It is the same expression <code>getToken</code> returns for a <code>transform</code>:</Ink>

```tsx
getToken("color:error", { transform: [null, null, "*0.5", null] })
// hsl(from var(--np--color--error) h s calc(l * 0.5))
```

<Ink as="span">Channels are <code>[hue, saturation, lightness, alpha]</code>. A number sets the channel, <code>"+30"</code> and <code>"-30"</code> shift it, <code>"*0.5"</code> scales it, and <code>null</code> leaves it alone.</Ink>
