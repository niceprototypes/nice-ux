## getHSLA

<Typography>
  <code>getHSLA</code> reads a token's <code>hsla</code> value for a given theme,
  then adds per-channel <code>[hue, saturation, lightness, alpha]</code> deltas —
  clamping each channel to its range (hue 0–360, saturation/lightness 0–100,
  alpha 0–1) with a console warning on clamp. It's the same hue-preserving
  technique used to derive the light (day) and dark (night) state background fills.
</Typography>
