## Get breakpoints

Configure your design for **different screen sizes and ranges** by tweaking breakpoint variants for tokens and components, or by using `getBreakpoint` in your style code.

<NewLines />

### Use breakpoints directly

<NewLines />

#### CSS only

```css
@import "nice-styles/tokens.css";

.phone-only {
  font-size: var(--np--font-size--phone);
}
.laptop-only {
  font-size: var(--np--font-size--laptop);
}
.desktop-only {
  font-size: var(--np--font-size--desktop);
}
```

<NewLines />

#### JS + CSS

[//]: # "For CSS-in-JS or runtime CSS strings, `getBreakpoint` returns the matching `@media (min-width: …)` literal sourced from the same threshold table the build uses, so JS and CSS stay in sync:"

```js
import { getBreakpoint, getToken } from "nice-styles"

const css = `${getBreakpoint("desktop")} {
  h1 {
    font-size: ${getToken("fontSize", "larger")};
  }
}`
```

<Callout type="learning">Calling `getToken` inside of an instance of `getBreakpoint` will automatically resolve to the correct breakpoint variant.</Callout>

<NewLines />

### Styled Components

[//]: # "The same `getBreakpoint` literal drops straight into a styled-component, paired with `getToken` for the values — JS and CSS stay on one threshold table:"

```bash
npm install nice-react-styles styled-components
```

```tsx
import styled from "styled-components"
import { getBreakpoint, getToken } from "nice-react-styles"

const Wrapper = styled.div`
  padding: ${getToken("gap")};

  ${getBreakpoint("laptop")} {
    padding: ${getToken("gap", "large")};
  }
`
```

## Set breakpoints

Imperative override of the pixel thresholds behind `@media` queries. `BREAKPOINTS`
is mutated in memory and a `<style data-nice-breakpoints>` element is injected
into `<head>` with the re-emitted `@media` cascade. Cascade order means the
injected stylesheet overrides the build-time literals from `tokens.css`.

There are two ways in: call `setBreakpoints` directly, or pass a top-level
`breakpoints` key to [`setTokens`](/docs/react-settokens--docs). `setTokens`
forwards **only** that key to `setBreakpoints` (splitting it out before token CSS
is emitted, so the new thresholds apply to the same pass); every other key
becomes a flat or component token. `setTokens` with no `breakpoints` key never
touches breakpoints.

### Usage

```ts
import { setBreakpoints } from "nice-react-styles"

setBreakpoints({
  tablet: 700,
  laptop: 1100,
  desktop: 1800,
})
```

Accepts `Partial<BreakpointValues>` — any subset of the editable floors
`tablet` / `laptop` / `desktop`; omitted keys are preserved. `phone` is the
implicit mobile-first base and is not settable — its ceiling tracks `tablet`.

Reach for this directly when thresholds need to change after initial load —
a settings toggle, an A/B test, a unit test. For static per-app config that
belongs with the rest of your design tokens, use
[`setTokens({ breakpoints })`](/docs/react-settokens--docs)
instead.

## Defaults

Keys used in `breakpoints` maps and `$breakpoints` objects. A bare name matches
that band **exactly**; `+` extends it **up** (that breakpoint and larger), `-`
extends it **down** (that breakpoint and smaller).

<DataSection
  inline
  columns={[
    { key: "name", header: null, width: "5em", render: "node" },
    { key: "query", header: "Query", width: "29em", render: "shiki", language: "css" },
    { key: "range", header: "Range", render: "text", code: true, size: "small" },
  ]}
  tables={[{ rows: [
    { id: "phone", values: ["phone", "@media (max-width: 640px)", "<= 640"] },
    { id: "tablet", values: ["tablet", "@media (min-width: 641px) and (max-width: 1279px)", "641-1279"] },
    { id: "laptop", values: ["laptop", "@media (min-width: 1280px) and (max-width: 1719px)", "1280-1719"] },
    { id: "desktop", values: ["desktop", "@media (min-width: 1720px)", ">= 1720"] },
    { id: "tablet+", values: ["tablet+", "@media (min-width: 641px)", ">= 641"] },
    { id: "laptop+", values: ["laptop+", "@media (min-width: 1280px)", ">= 1280"] },
    { id: "tablet-", values: ["tablet-", "@media (max-width: 1279px)", "<= 1279"] },
    { id: "laptop-", values: ["laptop-", "@media (max-width: 1719px)", "<= 1719"] },
  ] }]}
/>

<Callout type="hint">`phone+` and `desktop-` span every width — applied at `:root` with no `@media`. `phone-` ≡ `phone` and `desktop+` ≡ `desktop`.</Callout>
