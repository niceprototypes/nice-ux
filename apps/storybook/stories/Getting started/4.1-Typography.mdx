# Typography

First component consumer. Default tokens, no overrides.

### Mount

```tsx
import { StylesProvider } from "nice-react-styles"
import Typography from "nice-react-typography"

<StylesProvider loadFonts>
  <Typography as="h1" size="larger" weight="bold">
    Hello
  </Typography>
  <Typography color="medium">
    Body copy.
  </Typography>
</StylesProvider>
```

### Token-driven props

| Prop      | Token group         |
|-----------|---------------------|
| `size`    | `fontSize`          |
| `color`   | `foregroundColor`   |
| `weight`  | `fontWeight`        |
| `as`      | `h1` / `h2` / `h3` / `h4` / `p` / `span` |
