# Simple tokens


## Direct use

The most direct way to use nice-styles: install, import the stylesheet, reference the CSS variables. No build step, no JS runtime.
<LineBreaks lines={2}/>

<Install package="styles" />

### 2. Import stylesheet

```css
@import "nice-styles/tokens.css";
```

### 3. Use tokens

```css
.message {
  color: var(--np--color--base);

  &.success {
    color: var(--np--color--success);
  }

  &.error {
    color: var(--np--color--error);
  }
}
```

---

## Creating local aliases

You may choose to alias Nice tokens and reference your names everywhere else.
<br/>

```css
@import "nice-styles/tokens.css";

:root {
  --color--base:    var(--np--color--base);
  --color--success: var(--np--color--success);
  --color--error:   var(--np--color--error);
}

.message {
  color: var(--color--base);

  &.success {
    color: var(--color--success);
  }

  &.error {
    color: var(--color--error);
  }
}
```
