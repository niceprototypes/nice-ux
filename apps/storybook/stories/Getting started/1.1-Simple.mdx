# Simple

Static design tokens. No breakpoints, no React.

### Use a token in CSS

```css
@import "nice-styles/variables.css";

.card {
  padding: var(--np--gap--base);
  background: var(--np--background-color--alternate);
  border-radius: var(--np--border-radius--base);
}
```

### Use a token in JS

```ts
import { getToken } from "nice-styles"

getToken("fontSize", "base")
// { key: "--np--font-size--base", var: "var(--np--font-size--base)", value: "16px" }
```

### Token groups

`animationDuration`, `animationEasing`, `backgroundColor`, `backgroundSize`,
`borderColor`, `borderRadius`, `borderWidth`, `boxShadow`, `cellHeight`,
`fontFamily`, `fontSize`, `fontWeight`, `foregroundColor`, `gap`, `lineHeight`.

### Variant scale

```
smaller → small → base → large → larger
```
