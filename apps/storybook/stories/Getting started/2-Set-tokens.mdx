## 1. Call the setter function

Call `setTokens` once on module load:

```ts
import { setTokens } from "nice-react-styles"

setTokens({
  // Static module
  fontSize: {
    base: "18px", // Static token
    jumbo: "96px", // Custom token
  },
  // Custom module
  brandColor: {
    primary: "#dc0000",
    secondary: "#1a1a1a",
  },
} as const)
```

> **Note:** Modules and tokens can be modified (static) or created (custom) in the same object.

## 2. Wrap subtree with provider

`App` can now consume the tokens:

```tsx
import { StylesProvider } from "nice-react-styles"
import "./tokens.ts"

<StylesProvider>
  <App />
</StylesProvider>
```

<NewLines/>

## 3. Access new tokens

New tokens can be accessed by the getter function:

```tsx
// App.tsx

import { getToken } from "nice-react-styles"

getToken("fontSize", "larger")       // var(--np--font-size--larger)    → 48px
getToken("fontSize", "jumbo")       // var(--np--font-size--jumbo)      → 96px
getToken("brandColor", "primary")   // var(--np--brand-color--primary)  → #dc0000
```
