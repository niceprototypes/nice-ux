# 4. React setters

Override core tokens and register custom token groups via `createTokens()`.
Returns a `GlobalStyles` component that injects the resulting CSS variables.

```tsx
import { createTokens } from "nice-react-styles"

export const { GlobalStyles } = createTokens({ /* token map */ } as const)
```

Mount `GlobalStyles` once, inside `StylesProvider`:

```tsx
<StylesProvider loadFonts>
  <GlobalStyles />
  <App />
</StylesProvider>
```
