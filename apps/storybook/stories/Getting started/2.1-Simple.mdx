# Styles only

No fonts, no responsive overrides. Just `StylesProvider` + `getReactToken`.

### Wrap the app

```tsx
import { StylesProvider } from "nice-react-styles"

export default function App() {
  return (
    <StylesProvider>
      <Page />
    </StylesProvider>
  )
}
```

### Read tokens in styled-components

```tsx
import styled from "styled-components"
import { getReactToken } from "nice-react-styles"

const Card = styled.div`
  padding: ${getReactToken("gap", "base")};
  background: ${getReactToken("backgroundColor", "alternate")};
  border-radius: ${getReactToken("borderRadius", "base")};
`
```

`getReactToken(group, variant)` returns `{ key, var, value }`. Use `.var` inside CSS.
