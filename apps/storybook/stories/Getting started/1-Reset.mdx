[//]: # (`nice-styles/reset.css` is a static, **token-driven** baseline following the modern _sensible-reset_ model — it **provides** design-system defaults rather than stripping to a blank slate. It sets the box model, strips margins &#40;leaving list and control padding intact&#41;, wires the document **and heading** typography to tokens, makes media block-level and fluid, indents lists to a gap token, balances heading wrapping, and inherits fonts into form controls. It reads `var&#40;--np--…&#41;` values, so it must be imported **after** `tokens.css`.)
