# Simple tokens

**Example:** Using Nice color [tokens](/?path=/docs/tokens-styles--docs) to set up

## 1. Install

```bash
npm install nice-styles
```

## 2. Define local aliases

```css
@import "nice-styles/variables.css";

:root {
  --success: var(--np--foreground-color--success);
  --warning: var(--np--foreground-color--warning);
  --error:   var(--np--foreground-color--error);
  --link:    var(--np--foreground-color--link);
}
```

## 3. Usage

```css
.toast--success { color: var(--success); }
.toast--error   { color: var(--error); }
```
