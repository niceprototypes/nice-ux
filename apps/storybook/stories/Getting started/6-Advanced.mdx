## From scratch

If you don't have a design token system or want to replace your existing one, here's how to get going:

<NewLines />

### 1. Wrap subtree with provider

`App` can now consume the tokens:

```tsx
import { StylesProvider } from "nice-react-styles"
import "../tokens.ts"
import "../App"

<StylesProvider>
  <App />
</StylesProvider>
```

<NewLines />

### 2. Call the setter function

Call `setTokens` once on module load:

```ts
import { setTokens } from "nice-react-styles"

setTokens({
  // Static module
  fontSize: {
    base: "18px", // Static token
    jumbo: "96px", // Custom token
  },
  // Custom module
  brandColor: {
    primary: "#dc0000",
    secondary: "#1a1a1a",
  },
} as const)
```

> **Note:** Modules and tokens can be modified (static) or created (custom) in the same object.

<NewLines />

### 3. Access new tokens

New tokens can be accessed by the getter function:

```tsx
// App.tsx

import { getToken } from "nice-react-styles"

getToken("fontSize", { variant: "larger" }) // var(--np--font-size--larger)   → 48px
getToken("fontSize", { variant: "jumbo" })  // var(--np--font-size--jumbo)    → 96px
getToken("brandColor", { variant: "primary" }) // var(--np--brand-color--primary) → #dc0000
```

---

```tsx
import { setTokens } from "nice-react-styles"

setTokens({
  // STATIC MODULES

  // Basic module
  fontFamily: {
    // Static tokens
    base: "Open Sans",
    code: "Roboto Mono",
    // Custom tokens
    promo: "Billboard Sans Pro",
    numbers: "Calculator Mono",
  },

  // Themed module
  backgroundColor: {
    // Theme objects (static)
    base: {
      // Theme tokens (static)
      day: "#fff",
      night: "#000",
    },
  },

  // Responsive module
  fontSize: {
    // Responsive object (static)
    base: {
      // Responsive tokens (static) — phone is the required base
      phone: "16px",
      laptop: "24px",
      desktop: "32px",
    },
  },

  // CUSTOM MODULES

  brandColor: {
    // Custom keys
    primary: {
      // Theme tokens (static)
      day: "#dc0000",
      night: "#ff5050",
    },
  },
} as const)
```
