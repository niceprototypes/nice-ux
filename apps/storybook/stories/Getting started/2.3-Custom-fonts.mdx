# Styles + responsive + custom fonts

Load fonts via `StylesProvider`. Token getters and responsive behavior are
unchanged.

### Default Nice fonts

```tsx
import { StylesProvider } from "nice-react-styles"

<StylesProvider loadFonts>
  <App />
</StylesProvider>
```

Loads Google Sans Flex (base/heading) and Roboto Mono (code).

### Custom Google Fonts URL

```tsx
<StylesProvider googleFonts="https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap">
  <App />
</StylesProvider>
```

`fontFamily` token getters resolve through whatever font is loaded — no
component code changes.
