# Mode-pinned tokens

```bash
npm install nice-styles
```

```css
@import "nice-styles/tokens.css";

:root {
  --success-day:   var(--np--foreground-color--success--day);
  --warning-day:   var(--np--foreground-color--warning--day);
  --error-day:     var(--np--foreground-color--error--day);
  --link-day:      var(--np--foreground-color--link--day);

  --success-night: var(--np--foreground-color--success--night);
  --warning-night: var(--np--foreground-color--warning--night);
  --error-night:   var(--np--foreground-color--error--night);
  --link-night:    var(--np--foreground-color--link--night);
}

.toast--success      { color: var(--success); }
.toast--success.dark { color: var(--success-night); }
```
