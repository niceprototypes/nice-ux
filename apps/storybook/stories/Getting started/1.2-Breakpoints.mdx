# Breakpoints

Tokens that change value across viewport widths. Phone is the default — values
apply with no media query. Larger breakpoints override via `min-width` queries.

| Breakpoint | Range |
|------------|-------|
| `phone`    | 0–640px (default) |
| `tablet`   | 641–1279px |
| `laptop`   | 1280–1719px |
| `desktop`  | 1720px+ |

### Generated CSS

```css
:root {
  --np--font-size--base: 14px;             /* phone default */
  --np--font-size--base--laptop: 16px;     /* primitive */
  --np--font-size--base--desktop: 18px;    /* primitive */
}

@media (min-width: 1280px) {
  :root { --np--font-size--base: var(--np--font-size--base--laptop); }
}

@media (min-width: 1720px) {
  :root { --np--font-size--base: var(--np--font-size--base--desktop); }
}
```

### Read a breakpoint in JS

```ts
import { getBreakpoint } from "nice-styles"

getBreakpoint("laptop")
// { value: 1280, query: "(min-width: 1280px)" }
```
