# Utility classes

The token CSS variables in `tokens.css` are the foundation. For repetitive shorthand — padding, gap, type scale — you can wrap them in utility classes and apply them inline in markup, much like Tailwind but driven by your own token registry.

## Define classes

<Install package="styles" />

```css
@import "nice-styles/tokens.css";

.padding-smaller { padding: var(--np--gap--smaller); }
.padding-small   { padding: var(--np--gap--small); }
.padding-base    { padding: var(--np--gap--base); }
.padding-large   { padding: var(--np--gap--large); }
.padding-larger  { padding: var(--np--gap--larger); }
```

## Use in markup

```html
<div class="padding-base">…</div>
```

The utility approach trades a bit of markup density for fewer custom class definitions across your app — useful when many components share the same handful of spacing or sizing combinations.
