Standalone SVG icon library. Framework-agnostic — use them as `<img>` sources,
inline SVG, or through the React [Icon component](/docs/react-components-icon--docs).

## Standalone (any framework)

```jsx
import CheckIcon from "nice-icons/check/stroke.svg"

<img
  src={CheckIcon}
  alt="check"
/>
```

## React

```bash
npm install nice-react-icon
```

```tsx
import Icon from "nice-react-icon"

<Icon name="check" size="large" />
```
