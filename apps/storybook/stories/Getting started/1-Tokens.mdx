## Direct use

The most direct way to use nice-styles: install, import the stylesheet, reference the CSS variables. No build step, no JS runtime.

<Install package="styles" />

### 2. Use tokens

```css
@import "nice-styles/tokens.css";

.message {
  color: var(--np--color--base);
}

.message.success {
  color: var(--np--color--success);
}

.message.error {
  color: var(--np--color--error);
}
```

## Local aliases

You may choose to alias the Nice UI tokens you need, and use your aliases everywhere else.

### 1. Define aliases

```css
@import "nice-styles/tokens.css";

:root {
  --color--base:    var(--np--color--base);
  --color--success: var(--np--color--success);
  --color--error:   var(--np--color--error);
}
```

### 2. Use aliases

```css
.message {
  color: var(--color--base);
}

.message.success {
  color: var(--color--success);
}

.message.error {
  color: var(--color--error);
}
```

## JavaScript

#### JS only

Use the `getToken` function and CSS variables provided by `nice-styles` for vanilla JS:

```js
import { getToken } from "nice-styles"
import "nice-styles/tokens.css"

// Create HTML element
const card = document.createElement("div")

// Apply token values
card.style.padding = getToken("gap", "large")
card.style.backgroundColor = getToken("backgroundColor")
card.style.borderRadius = getToken("borderRadius", "small")

// Append element to DOM
document.body.append(card)
```

#### React only

Create and style a React component with tokens:

```tsx
import { getToken } from "nice-react-styles"

export default function Card({ children }) {
  return (
    <div
      style={{
        padding: getToken("gap", "large"),
        backgroundColor: getToken("backgroundColor"),
        borderRadius: getToken("borderRadius", "small"),
      }}
    >
      {children}
    </div>
  )
}
```

Render the React component inside `StylesProvider`:

```tsx
import { StylesProvider } from "nice-react-styles"

export default function App() {
  return (
    <StylesProvider>
      <Card>…</Card>
    </StylesProvider>
  )
}
```

#### React + Styled Components

Create and style a Styled Component with tokens:

```tsx
import { getToken } from "nice-react-styles"

const Card = styled.div`
  padding: ${getToken("gap", "large")};
  background-color: ${getToken("backgroundColor")};
  border-radius: ${getToken("borderRadius", "small")};
`
```

Render the Styled Component inside `StylesProvider`:

```tsx
import { StylesProvider, getToken } from "nice-react-styles"
import styled from "styled-components"

export default function App() {
  return (
    <StylesProvider>
      <Page>
        <Card>…</Card>
      </Page>
    </StylesProvider>
  )
}
```

## Setting tokens

### 1. Call the setter function

Call `setTokens` once on module load:

```ts
// tokens.ts
import { setTokens } from "nice-react-styles"

setTokens({
  // Static token
  fontSize: {
    base: "18px",
    larger: "48px",
    jumbo: "96px", // Custom key
  },
  // Custom token
  brandColor: {
    primary: "#dc0000",
    secondary: "#1a1a1a",
  },
} as const)
```

<NewLines/>

### 2. Wrap subtree with provider

`App` can now consume the tokens:

```tsx
import { StylesProvider } from "nice-react-styles"
import "./tokens.ts"

<StylesProvider>
  <App />
</StylesProvider>
```

<NewLines/>

### 3. Access new tokens

New tokens can be accessed by the getter function:

```tsx
import { getToken } from "nice-react-styles"

getToken("fontSize", "larger")       // var(--np--font-size--larger)    → 48px
getToken("fontSize", "jumbo")       // var(--np--font-size--jumbo)      → 96px
getToken("brandColor", "primary")   // var(--np--brand-color--primary)  → #dc0000
```
