# Styles + fonts + responsive

A variant value can be a static string, a breakpoint object, or a mode object.
Detected automatically by `createTokens()`.

| Format       | Trigger key | Example                                  |
|--------------|-------------|------------------------------------------|
| Static       | (string)    | `"16px"`                                 |
| Breakpoints  | `phone`     | `{ phone: "16px", laptop: "24px" }`      |
| Modes        | `day`       | `{ day: "#000", night: "#fff" }`         |

Detection order: breakpoint → mode → static. If an object has both `phone`
and `day`, breakpoint wins.

### Mixed example

```tsx
import { createTokens } from "nice-react-styles"

export const { GlobalStyles } = createTokens({
  gap: {
    none: "0",                                     // static
    base: { phone: "16px", laptop: "24px" },       // breakpoint
  },
  fontSize: {
    larger: { phone: "28px", laptop: "40px", desktop: "48px" },
  },
  brandColor: {
    primary: { day: "#dc0000", night: "#ff5050" }, // mode
    accent:  "#1a1a1a",                            // static
  },
} as const)
```

### Generated CSS (sketch)

```css
:root {
  --np--gap--base: 16px;                              /* phone default */
  --np--gap--base--laptop: 24px;
  --np--brand-color--primary--day: #dc0000;
  --np--brand-color--primary--night: #ff5050;
  --np--brand-color--primary: var(--np--brand-color--primary--day);
}

@media (min-width: 1280px) {
  :root { --np--gap--base: var(--np--gap--base--laptop); }
}

@media (prefers-color-scheme: dark) {
  :root { --np--brand-color--primary: var(--np--brand-color--primary--night); }
}
```

The `--day` and `--night` primitives are stable — they are never reassigned
by media queries.
