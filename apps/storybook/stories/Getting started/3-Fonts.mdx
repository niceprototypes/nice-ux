### 2. Wrap subtree with provider

#### Google Fonts

`fonts.googleapis.com` `fonts.gstatic.com` preconnects and stylesheet injected into `<head>`:

```tsx
import { StylesProvider } from "nice-react-styles"

<StylesProvider googleFonts="https://fonts.googleapis.com/…">
  <App />
</StylesProvider>
```

<NewLines />

#### Adobe Fonts

`use.typekit.net` preconnects and stylesheet injected into `<head>`:

```tsx
import { StylesProvider } from "nice-react-styles"

<StylesProvider adobeFonts="https://use.typekit.net/…">
  <App />
</StylesProvider>
```

### 3. Change fonts

Call `setTokens` once on module load:

```tsx
import { setTokens } from "nice-react-styles"

setTokens({
  fontFamily: {
    base: "'Inter', sans-serif",
    heading: "'Lora', serif",
  },
})
```

Here `base` and `heading` switch to the loaded fonts while `code` keeps its default. Call `setTokens` once at module load (e.g. `src/nice/tokens.ts`) and import that file for its side effect — every component that uses `fontFamily` tokens now renders with the new typeface.
