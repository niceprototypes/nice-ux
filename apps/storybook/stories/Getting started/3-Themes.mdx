## Pinning a theme with HTML

<Install package="styles" />

<NewLines/>

### 2. Pin the theme

You can pin the theme to a whole page via the `html` element:

```html
<html data-theme="day">…</html>
```

Or pin to an element by setting the attribute:

```html
<section data-theme="night">…</section>
```

<NewLines/>

### 3. Use semantic tokens

Semantic tokens within the pinned element are reassigned to the pinned theme value:

```html
<section>
  <p style="color: var(--np--color--base)">
    Pinned to browser
  </p>
</section>

<section data-theme="night">
  <p style="color: var(--np--color--base)">
    Pinned to night
  </p>
  <p style="color: var(--np--color--base--day)">
    Pinned to day
  </p>
</section>
```

## Pinning a theme with CSS

Use the CSS tokens to pin the theme to a selector:

```css
@import "nice-styles/tokens.css";

body.night-mode {
  background-color: var(--np--background-color--base--night);
  color: var(--np--color--base--night);
}
```

## Pinning a theme with React

### `theme` prop

For pinning any Nice component:

```tsx
import Typography from "nice-react-typography"

<Typography theme="night">Night mode</Typography>
```

<NewLines/>

### `Theme` component

For pinning React subtrees:

```tsx
import { Theme } from "nice-react-styles"

<Theme name="day">
  {children}
</Theme>
```

<NewLines/>

### Nesting

Additionally, you can nest pinned components within a pinned `Theme`:

```tsx
import { Theme } from "nice-react-styles"

<Theme name="day">
  <Typography>Day mode</Typography>
  <Typography theme="night">Night mode</Typography>
</Theme>
```

Or even within other pinned components:

```tsx
import { Theme } from "nice-react-styles"

<Theme name="night">
  <Typography>Night</Typography>
  <Tile theme="day">
    <Typography>Day</Typography>
    <Typography theme="night">Night</Typography>
  </Tile>
</Theme>
```
