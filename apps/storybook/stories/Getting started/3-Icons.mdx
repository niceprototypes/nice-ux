## Standalone

Access all **stroke and fill variants** of all icons via the `nice-icons` package:

```bash
npm install nice-icons
```

### Stroke

```jsx
import CheckStrokeIcon from "nice-icons/check/stroke.svg"

<img src={CheckStrokeIcon} />
```


### Fill

```jsx
import CheckFillIcon from "nice-icons/check/fill.svg"

<img src={CheckFillIcon} />
```

## React

The Icon component allows you to **easily configure icon properties** without any CSS code:

```bash
npm install nice-react-icon
```

```tsx
import Icon from "nice-react-icon"

<Icon
  name="check"
  size="large"
  color="link"
  strokeWidth="base"
  strokeScaling
  outlined
  theme="day"
  viewBox="0 0 24 24"
  vendor
  url="https://example.com/icon.svg"
  vendorComponent={CustomIcon}
  className="my-icon"
  style={{ opacity: 0.8 }}
/>
```

<Callout type="hint">See the [Component](/docs/components-icon--docs) page for full documentation.</Callout>

## getIcon

When you need the **raw SVG component** rather than the styled `Icon` — to drop
into your own markup, pass to a third-party API, or render outside React's token
context — `getIcon` resolves an icon name to its underlying component:

```tsx
import { getIcon } from "nice-react-icon"

const CheckIcon = getIcon("check")          // stroke variant (default)
const CheckFill = getIcon("check", true)    // outlined → fill variant

<CheckIcon />
```

Returns the icon's React component, or `undefined` when the name isn't in the
set. The second argument picks the variant: `false` (default) for stroke,
`true` for fill.
