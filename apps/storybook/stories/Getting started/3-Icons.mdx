## React

The Icon component allows you to **easily configure icon properties** without any CSS code:

<Install package="react-icon" />

```tsx
<Icon
  name="check"
  size="large"
  color="link"
  strokeWidth="base"
  strokeScaling
  outlined
  theme="day"
  viewBox="0 0 24 24"
  vendor
  url="https://example.com/icon.svg"
  vendorComponent={CustomIcon}
  className="my-icon"
  style={{ opacity: 0.8 }}
/>
```

<Callout type="hint">
  See the [Component](/docs/components-icon--docs) page for full documentation.
</Callout>

## getIcon

Access raw SVG files for a React project:

```tsx
import { getIcon } from "nice-react-icon"

const CheckIcon = getIcon("check")          // stroke variant (default)
const CheckFill = getIcon("check", true)    // outlined → fill variant

<CheckIcon />
```

Returns the icon's React component, or `undefined` when the name isn't in the
set. The second argument picks the variant: `false` (default) for stroke,
`true` for fill.

<Callout type="hint">
  Every icon name accepted by `getIcon` and the `Icon` component is listed
  below.
</Callout>
