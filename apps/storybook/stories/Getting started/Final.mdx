Everything from the previous pages in one place: register token overrides (colors, fonts, responsive sizes) with `setTokens`, load a web font, wrap the app in `StylesProvider`, and render components.

```bash
npm install nice-react-styles nice-react-typography styled-components
```

## 1. Define your tokens

`setTokens` runs once at module load for its side effect — overriding core variants and registering any custom groups. Static, responsive (`{ phone, laptop, … }`), and theme (`{ day, night }`) values can be mixed freely.

```ts
// nice/tokens.ts
import { setTokens } from "nice-react-styles"

setTokens({
  // Re-color text
  color: {
    base: "#1a1a1a",
    medium: "#4a5568",
  },

  // Swap font family
  fontFamily: {
    base: "'Inter', sans-serif",
    heading: "'Playfair Display', serif",
  },

  // Responsive font sizes
  fontSize: {
    base:   { phone: "16px", laptop: "18px" },
    larger: { phone: "32px", laptop: "44px", desktop: "56px" },
  },
} as const)
```

## 2. Load fonts and mount the provider

Import the tokens module once for its side effect, load the web fonts via `googleFonts`, and wrap the tree in `StylesProvider`.

```tsx
import "./nice/tokens"
import { StylesProvider } from "nice-react-styles"
import Typography from "nice-react-typography"

<StylesProvider googleFonts="https://fonts.googleapis.com/css2?family=Inter:wght@400;700&family=Playfair+Display:wght@700&display=swap">
  <Typography as="h1" size="larger" weight="bold">
    Heading scales with viewport
  </Typography>
  <Typography>Body copy uses Inter.</Typography>
</StylesProvider>
```

The full stack: tokens overridden, fonts loaded, components themed — no `GlobalStyles` component needed; the CSS is injected when `nice/tokens` is imported.
