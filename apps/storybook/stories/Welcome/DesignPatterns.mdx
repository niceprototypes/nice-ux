# Design Patterns

**Want the Nice design pattern managing your project's styles?** Install
`nice-react-styles` to get a provider, typed token API, and font loading on top
of the base CSS tokens.

```bash
npm install nice-react-styles
```

> Support for Vue, Svelte, and other popular frameworks is coming soon.

- [StylesProvider](/docs/react-styles-stylesprovider--docs) — Wraps your app root to inject CSS variables and supply a styled-components theme
- [getToken](/docs/react-styles-gettoken--docs) — Typed accessor for token keys, CSS `var()` strings, and resolved values
- [createTokens](/docs/react-styles-createtokens--docs) — Register custom tokens and get back `GlobalStyles` plus a scoped `getToken`
- [useDeviceDetector](/docs/react-hooks-usedevicedetector--docs) — Detect mobile vs desktop viewport
