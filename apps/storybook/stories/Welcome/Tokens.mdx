# Tokens

**No framework required.** A complete token system built on CSS custom properties,
plus a standalone icon library. Works with any stack that renders HTML — static
sites, server-rendered pages, vanilla JS, or as a shared foundation across frameworks.

```bash
npm install nice-styles
```

- [Styles](/docs/tokens-styles--docs) — Colors, typography, spacing, etc.
- [Responsive](/docs/tokens-responsive--docs) — Breakpoints and media query helpers
- [Icons](/docs/tokens-icons--docs) — Nice icon set
