# nice-css-variables

A collection of CSS custom properties (variables) for consistent design tokens across your application.

## Overview

`nice-css-variables` provides a comprehensive set of CSS custom properties organized in levels for systematic theming and consistent design patterns.

## Installation

```bash
npm install nice-css-variables
```

## Usage

### Import in Your App

```css
/* In your main CSS file or index.css */
@import 'nice-css-variables';
```

Or import directly in JavaScript/TypeScript:

```javascript
import 'nice-css-variables'
```

### In Storybook

Add to `.storybook/preview-head.html`:

```html
<style>
  @import url('../node_modules/nice-css-variables/variables.css');
</style>
```

## Variable Categories

### Level 0: Base Variables

#### Animation
- `--animation-duration-1`: 300ms (quick transitions)
- `--animation-duration-2`: 600ms (slower animations)
- `--animation-easing-1`: ease-in-out

#### Background Colors
- `--background-color-1`: White (#ffffff)
- `--background-color-2`: Light gray (#f5f5f5)

#### Border Colors
- `--border-color-default`: Light border (#e8e8e8)
- `--border-color-primary`: Dark border (#404040)

#### Border Radius
- `--border-radius-1`: 4px (small)
- `--border-radius-2`: 8px (medium)
- `--border-radius-3`: 12px (large)
- `--border-radius-4`: 16px (extra large)

#### Border Width
- `--border-width-1`: 1.5px
- `--border-width-2`: 2px

#### Box Shadow
- `--box-shadow-1`: Subtle shadow (0 1px 4px)
- `--box-shadow-2`: Medium shadow (0 2px 8px)
- `--box-shadow-2-reverse`: Upward shadow

#### Cell Heights
- `--cell-height-1`: 24px (compact)
- `--cell-height-2`: 40px (small)
- `--cell-height-3`: 56px (medium)
- `--cell-height-4`: 64px (large)
- `--cell-height-5`: 72px (extra large)

#### Content Colors
- `--content-color-1`: Almost black (#0d0d0d) - primary text
- `--content-color-2`: Dark gray (#616161) - secondary text
- `--content-color-3`: Medium gray (#999999) - muted text
- `--content-color-4`: Light gray (#d9d9d9) - disabled text

#### Status Colors
- `--content-color-active`: Blue (#00b4d8) - active state
- `--content-color-success`: Green (#2fb344) - success state
- `--content-color-error`: Red (#f05454) - error state
- `--content-color-warning`: Orange (#fb8500) - warning state

#### Font Family
- `--font-family-body`: System font stack for body text
- `--font-family-code`: Monospace font stack for code

#### Font Sizes
- `--font-size-1`: 12px (smallest)
- `--font-size-2`: 14px (small)
- `--font-size-3`: 16px (medium/default)
- `--font-size-4`: 20px (large)
- `--font-size-5`: 24px (extra large)

#### Gap Sizes
- `--gap-size-1`: 4px
- `--gap-size-2`: 8px
- `--gap-size-3`: 16px
- `--gap-size-4`: 32px
- `--gap-size-5`: 48px

#### Icon Stroke Width
- `--icon-stroke-width-1`: 1.5px (normal)
- `--icon-stroke-width-2`: 2px (bold)

#### Line Height
- `--line-height-default`: 1.5 (comfortable reading)
- `--line-height-condensed`: 1.25 (compact text)

### Level 0: Brand Colors

Brand-specific colors for your application identity:

- `--brand-color-1`: #FF1A22 (primary red)
- `--brand-color-2`: #FF5D12 (orange-red)
- `--brand-color-3`: #FFAC38 (orange)
- `--brand-color-4`: #FFCF3F (yellow-orange)

### Level 1: Derived Variables

These variables build upon Level 0 variables:

#### Inverse Colors
- `--background-color-1-inverse`: Dark background (uses content-color-1)
- `--content-color-1-inverse`: Light text (uses background-color-1)

#### Status Colors (Aliases)
- `--content-color-default`: Default text (content-color-2)
- `--content-color-disabled`: Disabled text (content-color-4)

#### Icon Colors
- `--icon-stroke-color-default`: Default icon color (content-color-4)
- `--icon-stroke-color-primary`: Primary icon color (content-color-2)

## Usage Examples

### Using in CSS

```css
.my-button {
  padding: var(--gap-size-2);
  background-color: var(--background-color-1);
  border: var(--border-width-1) solid var(--border-color-default);
  border-radius: var(--border-radius-2);
  color: var(--content-color-1);
  font-size: var(--font-size-3);
  transition: all var(--animation-duration-1) var(--animation-easing-1);
}

.my-button:hover {
  background-color: var(--content-color-active);
  color: var(--content-color-1-inverse);
  box-shadow: var(--box-shadow-2);
}
```

### Using with styled-components

```tsx
import styled from 'styled-components'

const Button = styled.button`
  height: var(--cell-height-2);
  padding: 0 var(--gap-size-3);
  background-color: var(--content-color-active);
  color: white;
  border: none;
  border-radius: var(--border-radius-2);
  font-size: var(--font-size-2);
  font-weight: 500;
  cursor: pointer;
  transition: all var(--animation-duration-1);

  &:hover {
    background-color: var(--content-color-primary);
    box-shadow: var(--box-shadow-1);
  }

  &:disabled {
    background-color: var(--content-color-4);
    color: var(--content-color-3);
    cursor: not-allowed;
  }
`
```

### Status-based Styling

```tsx
const StatusBadge = styled.span<{ status: 'success' | 'error' | 'warning' }>`
  display: inline-block;
  padding: var(--gap-size-1) var(--gap-size-2);
  border-radius: var(--border-radius-1);
  font-size: var(--font-size-1);
  font-weight: 600;
  background-color: ${props => `var(--content-color-${props.status})`};
  color: white;
`

// Usage
<StatusBadge status="success">Success</StatusBadge>
<StatusBadge status="error">Error</StatusBadge>
<StatusBadge status="warning">Warning</StatusBadge>
```

### Spacing System

```tsx
const Card = styled.div`
  padding: var(--gap-size-3);
  margin-bottom: var(--gap-size-4);
  background-color: var(--background-color-1);
  border: var(--border-width-1) solid var(--border-color-default);
  border-radius: var(--border-radius-3);
  box-shadow: var(--box-shadow-1);
`

const CardHeader = styled.div`
  margin-bottom: var(--gap-size-2);
  padding-bottom: var(--gap-size-2);
  border-bottom: var(--border-width-1) solid var(--border-color-default);
`
```

## Variable Organization

### Gap Size Scale
The gap sizes follow a geometric progression:
- 1: 4px (micro spacing)
- 2: 8px (small spacing)
- 3: 16px (medium spacing, default)
- 4: 32px (large spacing)
- 5: 48px (extra large spacing)

### Font Size Scale
Font sizes are carefully chosen for readability:
- 1: 12px (labels, captions)
- 2: 14px (secondary text)
- 3: 16px (body text, default)
- 4: 20px (subheadings)
- 5: 24px (headings)

### Cell Height Scale
Heights designed for common UI components:
- 1: 24px (compact buttons/inputs)
- 2: 40px (standard buttons/inputs)
- 3: 56px (large buttons/inputs)
- 4: 64px (touch-friendly elements)
- 5: 72px (extra large touch targets)

## Customization

You can override any variable by defining it after importing nice-css-variables:

```css
@import 'nice-css-variables';

:root {
  /* Override default colors */
  --content-color-active: #007bff;
  --content-color-success: #28a745;

  /* Override spacing */
  --gap-size-3: 20px;

  /* Override brand colors */
  --brand-color-1: #your-brand-color;
}
```

## Best Practices

1. **Always use variables for consistency**: Instead of hardcoding colors/sizes, use the provided variables
2. **Follow the spacing scale**: Use gap-size variables for margins and padding
3. **Use semantic status colors**: Use status colors (success, error, warning) for their intended purposes
4. **Leverage the cell height scale**: Use cell-height variables for button and input heights
5. **Maintain hierarchy**: Use font sizes according to content hierarchy
6. **Override thoughtfully**: When overriding, maintain the visual harmony of the design system

- Easy customization through variable overrides
