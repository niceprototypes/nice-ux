# Nice React Components

Welcome to the comprehensive documentation for the **Nice React component library ecosystem**.

## 🎨 Component Library

A collection of flexible, customizable, and well-designed React components built with styled-components and TypeScript.

### React Components

- **[Flex](/docs/components-flex--docs)** - Responsive flexbox container with breakpoint support
- **[Typography](/docs/components-typography--docs)** - Semantic text component with status theming
- **[Tile](/docs/components-tile--docs)** - Full-width container with background support
- **[Button](/docs/components-button--docs)** - Feature-rich button with icons and theming
- **[Icon](/docs/components-icon--docs)** - 30+ built-in SVG icons with animations

### React Hooks

- **[useDeviceDetector](/docs/hooks-usedevicedetector--docs)** - Mobile device detection with debug mode

### Tools & Utilities

- **[CSS Variables](/docs/documentation-css-variables--docs)** - Design tokens and CSS custom properties
- **[nice-npm-link](/docs/documentation-nice-npm-link--docs)** - Enhanced npm linking tool

## 🚀 Getting Started

### Installation

Install the components you need:

```bash
# Core components
npm install nice-react-flex nice-react-typography
npm install nice-react-tile nice-react-button nice-react-icon

# Hooks
npm install nice-react-hook-device-detector

# CSS Variables (required for all components)
npm install nice-css-variables
```

### Import CSS Variables

All components depend on `nice-css-variables`. Import it in your app's entry point:

```javascript
// index.js or App.js
import 'nice-css-variables'
```

### Basic Usage

```tsx
import Flex from 'nice-react-flex'
import Typography from 'nice-react-typography'
import Button from 'nice-react-button'

function App() {
  return (
    <Flex direction="column" gap={3} type="padding" spacing={{ all: 3 }}>
      <Typography as="h1" size={5} weight={700}>
        Welcome to Nice React
      </Typography>

      <Typography as="p" size={3}>
        Build beautiful, responsive UIs with ease.
      </Typography>

      <Button
        status="primary"
        icon="arrow"
        onClick={() => alert('Hello!')}
      >
        Get Started
      </Button>
    </Flex>
  )
}
```

## 📦 Package Overview

### nice-react-flex
[![npm](https://img.shields.io/npm/v/nice-react-flex)](https://www.npmjs.com/package/nice-react-flex)

A highly flexible and responsive flexbox container with:
- Responsive breakpoints (sm/md/lg)
- Gap and spacing controls
- Padding/margin management
- Automatic prop normalization

### nice-react-typography
[![npm](https://img.shields.io/npm/v/nice-react-typography)](https://www.npmjs.com/package/nice-react-typography)

Semantic typography component with:
- HTML element selection (h1-h4, p, span)
- Size and weight controls
- Status-based colors
- Code styling support
- Text alignment options

### nice-react-tile
[![npm](https://img.shields.io/npm/v/nice-react-tile)](https://www.npmjs.com/package/nice-react-tile)

Full-width container for hero sections with:
- Background images and colors
- Customizable background properties
- Responsive breakpoints
- Built on Flex component

### nice-react-button
[![npm](https://img.shields.io/npm/v/nice-react-button)](https://www.npmjs.com/package/nice-react-button)

Comprehensive button component with:
- 4 sizes and multiple status variants
- Light/dark mode support
- Icon integration (left/right positioned)
- Full theming capabilities
- Accessibility built-in

### nice-react-icon
[![npm](https://img.shields.io/npm/v/nice-react-icon)](https://www.npmjs.com/package/nice-react-icon)

Icon component with 30+ built-in icons:
- Fill and stroke variants
- Custom SVG URL support
- Status-based theming
- Rotation and spinning animations
- 4 size variants

### nice-react-hook-device-detector
[![npm](https://img.shields.io/npm/v/nice-react-hook-device-detector)](https://www.npmjs.com/package/nice-react-hook-device-detector)

React hook for device detection:
- User agent detection
- Touch capability detection
- Viewport-based detection
- Debug mode for testing
- Responsive window resize handling

### nice-css-variables
[![npm](https://img.shields.io/npm/v/nice-css-variables)](https://www.npmjs.com/package/nice-css-variables)

Design token system with:
- Colors, spacing, typography
- Border radius and shadows
- Animation variables
- Brand color system
- Hierarchical organization

### nice-npm-link
[![npm](https://img.shields.io/npm/v/nice-npm-link)](https://www.npmjs.com/package/nice-npm-link)

Enhanced npm linking tool:
- Prevents React duplicate issues
- Auto-cleans node_modules
- Package manager detection
- Dry-run mode
- Better than npm link

## 🎯 Key Features

### Consistent Design System
All components use `nice-css-variables` for a cohesive design language across your application.

### TypeScript Support
Full TypeScript definitions for type safety and excellent IDE autocomplete.

### Responsive by Default
Components support responsive props with sm/md/lg breakpoints.

### Flexible Theming
Customize colors, spacing, and styling through CSS variables or component props.

### Well Documented
Comprehensive examples, API documentation, and usage guides for every component.

### Lightweight
Minimal dependencies (React, styled-components) with tree-shaking support.

## 🏗️ Architecture

### Component Dependencies

```
nice-react-button
  ├── nice-react-flex
  ├── nice-react-typography
  ├── nice-react-icon
  └── nice-css-variables

nice-react-tile
  ├── nice-react-flex
  └── nice-css-variables

nice-react-flex
  └── nice-css-variables

nice-react-typography
  └── nice-css-variables

nice-react-icon
  └── nice-css-variables
```

### Peer Dependencies

All components require:
- `react` >= 19.1.1
- `react-dom` >= 19.1.1 (except nice-react-icon where it's optional)
- `styled-components` >= 6.0.0

## 🔧 Development

### Local Development Setup

1. Clone all repositories:
```bash
git clone https://github.com/niceprototypes/nice-react-flex
git clone https://github.com/niceprototypes/nice-react-typography
# ... etc
```

2. Link local packages using `nice-npm-link`:
```bash
cd your-app
nnl ../nice-react-flex
nnl ../nice-react-typography
```

3. Start watch mode in component libraries:
```bash
cd ../nice-react-flex
npm run dev
```

### Building Components

Each component has standard npm scripts:

```bash
npm run build        # Build the component
npm run dev          # Watch mode
npm run test         # Run tests
npm run lint         # Lint code
npm run typecheck    # TypeScript check
```
