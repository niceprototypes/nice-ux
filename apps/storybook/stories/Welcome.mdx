# Nice Prototypes

A modular design system. Start with what you need — adopt more when you're ready.

---

### [🎨 Tokens](/docs/welcome-tokens--docs)

No framework required. A complete token system built on CSS custom properties,
plus a standalone icon library. Works with any stack that renders HTML.

### [⚙️ Bindings](/docs/welcome-bindings--docs)

React bindings for the token system — a provider, typed token API, font loading,
and utility hooks. Brings the Nice design pattern into your React project.

### [📱 Components](/docs/welcome-components--docs)

Pre-built React components that consume the token system out of the box.
Styled, responsive, and composable with zero configuration.
