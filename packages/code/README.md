# @niceprototypes/code

> **Responsive props:** Every prop accepts per-breakpoint overrides via the `breakpoints` array. See [withBreakpoints](https://niceprototypes.com/ui/?path=/docs/basics-breakpoints--docs).

A syntax-highlighted code block component for React. Renders a code string as [Shiki](https://shiki.style) dual-theme HTML (day/night via the `[data-theme]` cascade) with an optional language badge and click-to-copy. Part of the Nice Prototypes ecosystem.

Documentation for this package has moved to **[Storybook](https://niceprototypes.com/ui/)**.
