<StoryHeader title="Dedupe" />

<Ink><Ink>Remove duplicate singleton packages (react, styled-components, etc.) from linked packages'</Ink> <Ink code>node_modules</Ink><Ink>. This is the fix for</Ink> <Ink weight="semibold">"Invalid hook call"</Ink> <Ink>and styled-components context mismatches — both caused by more than one copy of a singleton being loaded at runtime.</Ink></Ink>

```bash
# Recurse across every file: linked package
nicely --dedupe

# Scope to one package
nicely --dedupe ../react-button

# Preview without deleting anything
nicely --dedupe --dry-run
```

<Line />

<Ink as="h2">What it removes</Ink>

<Ink>By default these are stripped from each linked package so the app's copy is the only one loaded:</Ink>

```bash
• react
• react-dom
• styled-components
• @types/react
• @types/react-dom
```

<Ink><Ink>Override or extend the set per run with</Ink> <Ink code>--exclude</Ink> <Ink>/</Ink> <Ink code>--add-exclude</Ink> <Ink>(see</Ink> <Ink><a href="/?path=/docs/cli-1-linking--docs" target="_top">Linking</a></Ink><Ink>).</Ink></Ink>

<Line />

<Ink as="h2">When to run it</Ink>

<ul>
  <li><Ink>After <code>npm install</code> inside a linked package (install re-adds the duplicates).</Ink></li>
  <li><Ink>After changing any <code>package.json</code> dependencies.</Ink></li>
  <li><Ink>Any time you hit "Invalid hook call" or a styled-components theme/context mismatch while developing against linked packages.</Ink></li>
</ul>

```bash
# Typical sequence after touching a linked package's deps
npm install
nicely --dedupe
```

<Ink><Ink code>--dedupe</Ink> <Ink>is also the second step of the workspace triad and of</Ink> <Ink code>--reset</Ink> <Ink>— see</Ink> <Ink><a href="/?path=/docs/cli-5-reset-caches--docs" target="_top">Reset & Caches</a></Ink><Ink>.</Ink></Ink>
