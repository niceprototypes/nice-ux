# @niceprototypes/styles

## 17.2.0

### Minor Changes

- d38d016: App: a `docsLink` prop, a book icon link after the search that opens the first docs section page in a new tab; both header icon buttons read `app.header.icon.color` and `app.header.focusRing.color` (`app.search.icon` is gone). Icon: `book-open`, adapted from Lucide (ISC).
- a279b9a: App: the scene sidebar is a resizable panel under the nav (no longer a column right of it), above the footer panel; both share one panel and handle (hidden scrollbars). `app.footer.*` tokens are now `app.panel.*`.
- a09cbae: App: the header row holds the Nice logo itself at `app.logo.height` (40; the `header` prop is gone) and, with the new `search` prop, a search button that expands into a field at the nav labels' size (`app.search.fontSize`, 16px floor below tablet), a gray icon that turns white on hover (`app.search.icon.color`), and a field with a gray focus border on pure black (night) or white (day) (`app.search.focusColor`, `app.search.backgroundColor`). Tree: `useTreeSize`, the label size a Tree renders at.
- 7c30e20: App: a resizable sidebar footer under the nav and the scene sidebar (useSceneSidebarFooter), with a separator drag handle (pointer and arrow keys) between the handle alone and its content's height; styles: app.footer._ and app.handle._ component tokens
- e7d3c28: App: the sidebar is at least `app.sidebar.minWidth` wide (styles: new component token, `auto` by default, so the default layout is unchanged; set it per breakpoint in a token map)
- b2ec456: App: the sidebar is a drawer below laptop (was below tablet). A `panelLabels` prop labels the two panels under the nav on their handle's line (`app.panel.label.*`); the handle row sits centred between the panel's top rule and its content (`app.handle.padding` is the large gap, as `app.handle.paddingBottom`).
- 661c953: Button: default label and border colours read the `button.color` / `button.borderColor` tokens (filled label: `button.color` inverse; inlined: `button.color:link`), so `setTokens({ button })` restyles a default button; the element-scoped height is the new `button.height` token; `iconSize`, `iconStrokeWidth` and `iconStrokeScaling` props; `loading` shows the spinner icon over the hidden content (width kept), sets `aria-busy` and ignores activation while staying focusable.
- 22473aa: Add @niceprototypes/card (Card, CardHeader, CardBody, CardFooter: outline, elevated or filled surface; static, link or toggle button), its `card.*` component tokens in styles, and its re-export from @niceprototypes/ux
- 3547207: Add @niceprototypes/chat: ChatLog (a `<Scroll follow>` log, `aria-busy` while streaming, a "Scroll to latest" button while not at the end), ChatMessage (user bubble or full-width assistant reply, an actions row on hover, focus within and the last message), ChatComposer (send on Enter, stop on the stop button or Escape while busy, `maxRows`), ChatSuggestions and ChatCopyAction; its `chat.*` component tokens in styles; its re-export from @niceprototypes/ux. Code exports its `copyToClipboard` service.
- b35f5fa: Add @niceprototypes/contents (Contents: an in-page table of contents with a sticky heading, nested section links, scroll-spy and smooth scroll), its `contents.*` component tokens in styles, and its re-export from @niceprototypes/ux. Code reads its card max-width from the new `code.maxWidth` token (720px, unchanged). Icon hides its wrapper from assistive technology, so an inline SVG's `<style>` text no longer joins the accessible name of the control around it.
- 2228ff5: Add @niceprototypes/markdown (Markdown: markdown text with headings, paragraphs and list items through Ink, fenced code through Code, inline code through `Code inlined`, links through `linkComponent` or an anchor, `overrides` merged over those, and each top-level block memoised so a streaming reply re-renders only its last block), its `markdown.gap` component token in styles, and its re-export from @niceprototypes/ux. App's docs pages render through Markdown, so their code renders as Code.
- 0f94a1c: Core overlayColor token (the scrim behind fullscreen overlays). lightbox: backgroundColor, image.maxWidth/maxHeight and caption.maxWidth/padding tokens; zIndex removed (the overlay is a top-layer dialog). toggle: transitionDuration renamed animationDuration, plus animationEasing. logo: height carries px units, gap reads the core gap; app.logo.height carries px.
- 7d1204d: Add @niceprototypes/radio (RadioGroup and Radio on native radios, wired to Field), its `radio.*` component tokens in styles, and its re-export from @niceprototypes/ux
- dfd23f0: Scroll: the scroll container every scrolling region renders through (`axis`, `showScrollbar`, `as`, `ref`). Scrollbars are hidden by default; the `scroll.scrollbarWidth` token sets the project default. Popover, List, Contents, Slider and the App shell's nav, sidebar, footer and scene region scroll through it.
- 8deec0e: Add @niceprototypes/tree (a navigation tree of nested links and disclosure folders with guide lines and a highlighted active path), its `tree.*` component tokens in styles, and its re-export from @niceprototypes/ux
- e1b9dc0: Tree rows take their height from content: the row `min-height` rule and the `tree.row.minHeight` token are removed.

### Patch Changes

- 6079566: App: an `end` prop, a column right of the scene region and outside it, `app.end.width` wide (24em) with the panels' rule on its start edge; laptop and up only, mounted across page changes.
- 69895e5: App: panel labels and drag handles rest at `app.panel.restOpacity` (0.5) and show fully while their row is hovered, the handle focused or dragged.
- 093696f: Scroll: a `follow` prop pins the scroll position to the end while the content grows; scrolling up releases the pin, the end pins it again. `useScrollEnd()` inside a `<Scroll follow>` returns `{ atEnd, scrollToEnd(behavior?) }`; `prefers-reduced-motion` makes the scroll instant. Styles: the `scroll.follow.threshold` token (`var(--np--gap)`).
